# STORMWAKE V80 · 深渊与采掘站更新

完整解压后运行 `00_START_V80.cmd`。单人使用 Python 3.10+、支持 WebGPU 的 Chrome/Edge；局域网房主还需 Node.js 22+，所有玩家使用同版本。无需 npm 安装即可通过 Python 启动。命令行：`python start_v80.py --mode solo --port 5173`。不要直接打开 index.html。

魔鲸号：V 切换舱内/外部观察；在岗位旁 E 操作/离岗；离岗并靠近隔舱门时 U 开关；工程台 J 排水、Y 维修（2.5秒，离岗取消）。每个分舱独立显示船体、水、氧，后舱电力和积水影响航行。外部视角不能无岗位维修。

沉岩洞：打败荒潮船长后在原深层岩心按 E 调查，再沿灯火进入新采掘站。西侧干路可直接往返，无需潜水。东侧储水池可游泳；采掘台按 E 登记，首次奖励120金币。矿样奖励以原岩心记录为前置，失败可重试。

本版保留原始游戏资产，新增逻辑、几何、测试与文档。它是完整工程更新，不是已经通过所有成品验收的商业发布版。未完成项详见 docs/V80_EXECUTION_zh.md。
