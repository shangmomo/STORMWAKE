# STORMWAKE V75 — 峡谷岩壁与远征船长交互

完整解压本归档，双击 `00_START_V75.cmd`。需要 Python 3.10+ 和支持 WebGPU 的 Chrome/Edge，联机房主需要 Node.js 22+。无需安装额外素材；V74 游戏资源保留。

## 新增内容
- Poly Haven Rock Face 01 (CC0)：原始 4K FBX 经专用转换器转换为独立 GLB，原始 20,174 个三角面全部保留，原始法线及 UV 逐面角保留。原始厘米单位及 X 轴 -90° 变换已烘焙。颜色贴图为 2K JPEG95，法线和粗糙度以线性空间转换为 2K PNG，法线降采样后归一化。五个岩壁站点共享几何和材质，使用各自的真实三角网格碰撞 BVH，远处按距离隐藏。主路中心线与五处岩壁碰撞包围盒均保留至少 2 米间距。
- 五处岩壁坐标：(355,-330)、(402,-394)、(431,-424)、(410,-595)、(348,-644)，原峡谷、化石谷和探险路线保持不变。
- KinemIQ/Quaternius CC0 动作库：本次 GLB 和 FBX ZIP 均含 35 个动作。游戏内附完整原始 GLB 动作源包（tools/v75_sources）；没有使用演示假人作为新角色。已将伸手互动 Action_interact（2秒）与交谈 Idle_talking（2.933秒）重定向到远征船长的 CAT 骨架。映射13个上半身关节，腿、根、手指和原模型保持不变。E 交互触发伸手、交谈、回到原待机，离开5米取消；反复按 E 不重置当前动画。原动作读取失败时回退到原始待机。
- 其他33个动作作为后续制作资源保留，未接入战斗、攀爬、坐下等状态机。远征船长仍为 NPC，不是荒潮船长 Boss；没有声称完成战斗角色更换。完整战斗重定向需要腿部 IK、武器握持及命中校准、蒙皮实机验收。
- 素材授权及哈希见 `public/models/expedition/v75/manifest.json` 与 `CREDITS.md`。原始岩壁 ZIP 未重复打包，转换后的 GLB 已内置。源转换脚本保留在 tools/v75_sources（从项目根目录运行，需 Python numpy、scipy、OpenCV 及 Pillow；游戏运行不需要这些库）。

Chromium EGL/GPU 初始化失败并超时，未完成 WebGPU 画面、帧率、视觉穿模或人工操作验收。CPU 蒙皮采样确认两个新动作的足部位置保持稳定、顶点无极端拉伸，但不能保证衣服/身体无局部穿插。五处岩壁的 CPU 碰撞检查不等同多人实机测试。
