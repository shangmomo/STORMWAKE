# STORMWAKE V77 — 古道补给与工坊

完整解压归档后运行 `00_START_V77.cmd`。单人使用 Python 3.10+ 和支持 WebGPU 的 Chrome/Edge，多人房主额外需要 Node.js 22+。原有资产未删除，兼容既有本地 v1 钱包存档；建议升级前备份浏览器游戏数据。

## 实际实现
- 古道铁匠工坊：在原建筑内服务点按 E，打开独立交易界面。短刃、长矛、钓竿各有三个强化等级，费用 70/140/250 金币。每级提升原始伤害 12%，四舍五入；不改变攻击半径、体力消耗、动画或命中时机。交易和等级保存使用同一个原钱包记录，存档写入失败回滚金币和等级。
- 远征酒馆：E 打开补给界面，18 金币恢复 40 生命、60 体力（上限 100），45 秒游戏内冷却。本次取消原免费重复恢复。无存储环境仅在当前会话生效。恢复与冷却不是跨重启存档状态。
- 服务权限：必须在场景已加载、正确高度、2.5m 范围和无遮挡情况下操作；战斗、攻击恢复、死亡、港口入侵均禁止。面板锁定移动及攻击输入，Esc 关闭；死亡/脱离范围自动关闭。联机时新交易和强化伤害不启用，等待服务器权威实现。
- 场景：两个服务点新增暖色局部照明；V75 岩壁、V76 场景、V74 岩洞不再重复读取和解析同一 GLB；植被及场景显示距离具有进入/退出滞回，减少阈值附近闪烁。未做实机 FPS 测量。
- 未添加任何新模型或降低现有资源几何质量，原作者署名保持。酒馆、铁匠铺原授权详情仍未核实，公开再分发前需确认许可。
