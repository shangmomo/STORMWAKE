# STORMWAKE V68 操舵、深潜协作与巨兽战斗修复版

完整包，无需旧版或补丁。解压后双击 `00_START_V68.cmd`（Python 3.10+；支持 WebGPU 的 Chrome/Edge；联机房主 Node.js 22+）。所有玩家使用同一版本。

## 海上船舵
- E 接管舵轮，面向船首；A 左、D 右；W 请求 AI 船员实际走向锚绞盘和帆索，起锚后展开主帆；S 收帆减速（不等于立即刹车或倒车）。保持风帆、风向、锚链物理约束；逆风时需换舷/转向，静风时仍不能凭空推进。低速舵力与帆风辅助已加强。
- 人类占用的岗位优先，AI 不抢占。F2 仍可设置海图自动航行。E 离岗。

## 深海魔鲸号
- 舱内两侧 12 个观察窗，船首全景观察窗；直接看到共享世界，无需切换摄像机，保留不可穿越的舱壁碰撞。当前为带边框的几何开口，不是折射玻璃；舱内模式本地隐藏原始外壳以免遮挡，其他摄像机仍显示原外模。
- 房主或队友均可走到驾驶台按 E 接管，按 E 离岗。驾驶权唯一，岗位占用/距离有服务器确认；没有驾驶员或远端输入超过 0.6 秒即归零。房主仍为战斗和物理模拟权威，不是唯一驾驶员。
- W/S 推进/倒车，A/D 左右转，Space 上浮，Ctrl/Q 下潜，N 停车，H 切换即时/持续油门。接管时视线朝船首，舒适模式倒车时也保持左右一致。鼠标环视。

## 海怪及 AI
- 海怪索敌与随机事件解绑，正常领地内可主动警戒、追击、蓄力和释放；开发者传送置于探测距离内，联机由房主传送共享船只。返回港口清理临时战斗导航。
- 船员依据威胁选安全侧向航路/撤离方向，实际操作锚、帆、舵与有限弹药火炮；在舷炮射界内计算提前量和弹道角，实体炮弹碰撞后伤害海怪。AI 仍遵循人类岗位优先、损管优先和射程/射界限制；不保证每次都命中或闪避成功。
- 不改 WebGPU/FFT 核心，不使用 Unity。沿用自研 WebGPU/WGSL，不宣称已迁移官方 Three.js + TSL。
