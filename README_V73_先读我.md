# STORMWAKE V73 · 陆地素材扩展

完整解压后运行 `00_START_V73.cmd`。需要 Python 3.10+ 和支持 WebGPU 的 Chrome / Edge；多人房主需要 Node.js 22+。四个素材已经放入游戏，不需要单独下载。原暴龙及其他 V72 功能保留。

## 新增内容
- 灰苔棕熊：活动中心 (-106,-191)，单人模式；警戒、巡游、追击、挥爪、收招、归巢、受击、死亡；首次狩猎奖励 60 金币。原始 81 个动作中选用 7 个；保留其他动作数据。使用原始骨骼，行走/快步的根位移去重，挥爪在 0.85 秒进行实际前爪与玩家胶囊接触检查。身体圆柱碰撞为近似代理。
- 东部古道石木旅舍： (113,-112)，源模型门封闭，作为外观地标，非可进入商店。主体外墙使用简化盒体碰撞。
- 古道远征会馆： (190,-190)，一层西侧入口约 (177,-190.52)，源模型门板与门廊阻挡网格被移除以形成开放入口。可沿实际楼面和入口进出。原始地下层尚未打通地形，上层楼梯未完成验收。
- 远征船长： (174.3,-187.4)，使用原始待机动画，接近后转身，E 获取情报。源模型仅包含一个待机动作，不具备攻击和移动动作，故未替换荒潮 Boss。

## 资产及限制
四个模型的作者、原始来源、授权、SHA256、纹理尺寸调整和修改节点记录见 `public/models/land/v73/manifest.json` 和 `CREDITS.md`。不重复打包用户已提供的原始 FBX ZIP。大型旅舍有约 33.7 万三角面，64 张原始贴图限制为最多 1K（保留原始网格和 PBR 通道）；其他新模型最多 2K。熊材质由无金属、无镜面反射的旧 specular-glossiness 描述转换为现有渲染器支持的 metallic-roughness。其余原始动画和贴图通道保留。没有新增低多边形替代模型。
