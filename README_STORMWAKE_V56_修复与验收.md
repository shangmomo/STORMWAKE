# STORMWAKE V56 — 船舱、绞锚、舵轮、海上生态修复记录

本包是在用户上传的 V54 工程及 V55 修复工程上进行的源码级修改，保留旧代码、资源、任务和联机服务。

## 启动

Windows 解压后双击 **00_START_V56.cmd**（或 `START_STORMWAKE_V56.cmd`），选择：**单人开始** / **多人·创建房间** / **多人·加入房间**。Python 3.10+；创建多人房间另需 Node.js 22+；推荐 Edge / Chrome 并开启 WebGPU。命令行检查可用：`python start_v56.py --mode solo --no-browser`。

## 本轮真实代码修改

1. **不再擅自开船。** `ShipStations` 默认：锚完全放下、起航油门为 0、两面帆为 0。`VoyageM1.beforePhysics()` 不再根据乘船/航点状态自动起锚；人工 W/S 绞锚是唯一升降方式。未升起的锚持续制动船体；完全收起后船才可离泊。不能用 R 开启自动模式。
2. **可操作多岗位绞盘。** 四个操作位共享统一锚链位移、轴转数和角色输入；扩大绞盘触发范围和优先级。靠近甲板中部绞盘按 **E**，按住 **W** 收锚链、按住 **S** 放锚链、按 **E** 离开；多人在四个岗位同时按 W 会加快收锚。木质转臂与原始荷兰船源模型的绞盘同时转动。
3. **船锚可见并联动。** 直接复用包内已许可的 `public/models/stormwake_v47/quaternius_prop_anchor.glb`（Quaternius CC0），调大到适合原船的尺寸，并将其定位在右舷锚孔外。增加延伸至船舷的金属链、甲板导链和导轮。锚在**完全放下**时位于水下，起锚后升至船舷可见位置，不是把已经放下的锚假装悬在船上。此模型不是本轮重新联网下载的外部文件，已包含在本包中。
4. **船舱水面遮罩。** `WaterMaterial.js` 更换封闭船体的分段截面遮罩，跟随船舶空间旋转，覆盖前、中、后船舱的海水体积，并保留船外水面。`App.js` 原有的封闭舱室相机抑制机制继续防止浪花、飞沫和水下效果从室内穿过。并非替换整套 FFT 海洋动力学。
5. **船舱防跌落。** `Player.js` 在主下层货舱与船长室分别加入防掉落捕获逻辑：步行地图/碰撞网格出现缝隙、角色坠至舱室下缘时，进入对应室内碰撞和地板高度，不直接跌入海底。主舱和船长室的物理路径分离。
6. **实体舵轮。** 在原船艉甲板新增木舵轮/轮架，修复旧美术舵轮被隐藏后没有替代物的情况；把舵轮位置改至船长室门侧，避免与舱门重合；方向输入会旋转舵轮视觉模型。
7. **陆地 Boss 大光球。** 删除营地四根杆上半径过大的蓝绿色球形装饰，改为小型暗色灯箱加暖光；不再把陆地 Corsair 临时渲染为放大 2.15 倍的 Warden 巨体。真正的皮肤模型加载后仍替换临时外形。
8. **夜间照明。** 在荷兰船模型中加入六组实物小灯笼，并在 `LocalLights.js` 增加船首、左右甲板、船长室、下层货舱的暖光位置与亮度。GPU 同时根据距离选择最多 8 盏局部灯光，不会把全部灯都当作高成本实时光源。
9. **远海生物。** `src/world/marine/OffshoreLife.js` 新增 16 只随船位置生成的鱼和海豚模型，浅海/陆地隐藏；鱼群绕船活动，部分鱼和海豚随机相位跃出海面。属于低开销**环境生物**，暂不含狩猎、碰撞和战斗 AI；原有鲸鱼、珊瑚礁鱼和海怪系统仍保留。
10. **地图自定义 AI 航点和联机同步**：沿用 V55 实现，继续通过测试，未切回任务固定航点。

## 未覆盖与必须实机验收的内容

**没有完成可交互的 WebGPU 图形游玩验收。** 当前沙箱 Chromium 对本地页面报告 `net::ERR_BLOCKED_BY_ADMINISTRATOR`；因此水面遮罩是否与所有浪高/舱室匹配、船锚从甲板视角能否无遮挡看见、船长室门口是否每处都可通行、Boss 帧动画以及 GPU 灯光强度都无法保证实机零问题。`npm run build` 因当前容器未安装 `vite` 而无法执行（打包不依赖它；浏览器由 Python 服务器直接提供源码）。本版是**已修改并通过逻辑测试的完整源工程**，不是已经在真实 WebGPU 渲染环境逐画面验收的最终 3A 成品。

建议本机优先按以下顺序实机测试：①陆地开局并上船；②保持锚放下时无法加速；③E 进入绞盘、W 起锚/ S 放锚、再开船；④舵轮旋转；⑤进出下层船舱和船长室并观察海面穿模及跌落；⑥傍晚和夜间甲板、下舱光照；⑦陆地 Boss；⑧航行到距原码头 150 米以外的水深大于 4 米海域观察鱼群；⑨两台电脑同时操作锚机并同步航点。
