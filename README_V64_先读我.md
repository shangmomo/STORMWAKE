# STORMWAKE V64 · 航行物理与船舱通行修复

2026-11-16。本版针对船上卡住、船长室、瞭望台、梯子、人物倒走、鱼竿提示遮挡，以及海图领航与帆力问题修改。V63 原目录保留。

解压整个文件夹，双击 **00_START_V64.cmd**。需要 Python 3.10+ 和支持 WebGPU 的 Edge / Chrome；多人房间还需要 Node.js 22+。请关闭旧版本页面，确认页面标题为 V64。模型随包提供。

## 本版操作

| 场景 | 操作与变化 |
|---|---|
| 普通船头、船尾楼梯 | WASD 直接走。前桅凹甲板两侧增加实际回程台阶；使用真实船模的地面与碰撞。 |
| 船长室 | E 只开关门，再用 WASD 走下入口阶梯；在室内可以走到桌前，再沿入口原路走出。低矮门框自动弯腰。 |
| 货舱、桅杆与舷侧梯 | 靠近梯口并朝向梯子，按住 W 上、S 下；松键停住，可反向返回。无需 E/C 启动自动爬梯。舷侧从甲板倒退下梯前同样面朝船内的梯子。 |
| 瞭望台 | 主桅、前桅都有可见平台、护栏与连续梯子，可以站立观察并沿原梯下来。 |
| 手动航行 | E 占用舵、锚机或帆索岗位，按岗位提示操作，E 离岗。舵只负责转向，W/S 不再提供隐藏发动机动力。需要收锚并放帆。 |
| 海图领航 | Z 打开海图，点击海上目标；AI 实际走到锚机、帆索和舵位，逐步收锚、放帆、操舵。选点时若本人占舵，会交出舵位。海图提供“取消领航”。真人占用岗位时优先。 |
| 鱼竿 | 航程中移除常驻“R 拿出鱼竿”提示；船上不再误激活旧版钓鱼系统。 |
| 人物 | 修正模型朝向、骨骼转轴和 AI 船员的船体缩放顺序，使用实际正向行走和作业姿态。 |

## 帆船规则

帆面积、风速、风向、调帆角度影响推力；无帆或无风时帆的推进力为零，顶风需要换舷。船仍受惯性、海浪与阻力影响，收帆不会立即停船。当前锚链长度约 34 米，深水区可能无法触底；领航到达后会收帆放锚并减速，但不保证在任意深水目标点静止停泊。
