# STORMWAKE V63

双击 `00_START_V63.cmd`，选择单人、创建房间或加入房间。需要 Python，以及支持 WebGPU 的 Edge / Chrome；创建多人房间还需要 Node.js 22+。素材随工程提供，游戏不会在运行时从素材网站下载模型。V60、V61、V62 原目录保留。

## 新航程入口

| 航程 | 开始与主要操作 |
|---|---|
| 失踪的海图师 | 船长室桌上的信件 E 接取。5 装备望远镜、右键举镜、对准线索 E 确认；船首鱼叉 E 发射，命中后按住 E 绞回并吊上甲板。下潜取日志，回桌阅读，登陆灰苔岛调查，返港找商人交付。 |
| 破帆的商船 | 港口商人 E 接取，循烟找到商船。沿实体登船踏板进入；从母船取木板和水桶，封堵两处破口并舀水，把货物搬回己船存舱，保持距离护送。 |
| 幽灯之夜 | 港口绿灯旁 E 接取，望远镜 E 确认幽灵船。舷炮攻击三盏实体桅灯解除防护，鱼叉打捞幽影匣；防守小艇上的登船者，或用航速甩开追赶，再存舱返港交付。 |
| 风暴航标 | 港口船匠 E 对话，选择航标委托；回船长室图台选择沿岸或直达航路。在航标旁下水，装备实际木板并按住 E 修理，再更换灯芯。返港才结算。 |
| 深渊回声 | 完成前三条航程后，分别在船长室、商人和绿灯处取组件，船匠处装配潜艇。随母船抵达深渊，从实体舱盖 E 进入、R 解缆，在同一世界下潜取样，上浮回母船，返港交付。 |

## 船与物资

- 普通楼梯使用 WASD；货舱梯 E/C，桅杆 C+W。成人胶囊会在低矮处调整姿态，货舱与船长室使用实际船体碰撞。
- 锚机 E 操作，W 收锚、S 放锚、E 离岗；四个把手可同时操作。锚、锚链、海底抓附、张力与转角使用同一状态。
- 舵 A/D 转向、W/S 辅机；帆索 W/S 收放、A/D 调角。四片原始船帆各自收拢在所属桁杆下。
- 从实体补给架拿取炮弹、链弹、木板和水桶，G 放到甲板。联机物资由房间统一管理，掉落物可由另一名船员捡起。
- 舷炮左键开火、R 装填。复位未完成时不会吞掉手里的炮弹。木板在实际修补完成时才消耗。
- 船匠商店消耗潮币，购买后货箱出现在工作台附近；必须搬回船舱存放，再 E 拆箱补入库存。潜艇探照灯和声呐可以升级。
- 货物与积水影响船体重量、重心和吃水。失去浮力后船体实际下沉，货物漂浮，船员可跳海；联机保存漂浮货物和沉没状态。
- V 切换第三人称，使用实际 CC0 骨骼和手持工具；远端人物同步行走、作业、战斗与受伤状态。绞盘手部已通过双客户端专项；全部动作及岗位仍在逐项验收。

## 潜艇

W/S 推进，A/D 转向，Space/C 上下潜；R 解缆或声呐，F 鱼雷，X 应急上浮。G 离开/接管驾驶位，离座后 WASD 在压力舱内行走。靠近样本、低速时按住 E 采集；水面停车 E 出舱。母船、海面、潜艇与海怪处于同一世界。

## 验证记录

当前工程持续按设计规格实现和验证。具体证据见 `docs/V63_IMPLEMENTATION_TRACKER.md` 与 `qa`；包含失败试次和修复后的结果。带位置布置的测试会明确标注，不作为完整航海通关或所有硬件性能的证明。尚未以现有测试宣称整个设计文档完成或“零 bug”。

开发检查：`npm ci`、`npm run test:v63`、`npm run build`。`tools/autoqa` 中的专项脚本通过真实 Edge / WebGPU、真实键盘和 WebSocket 验证交互。

验收压缩包包含完整运行源码、随附模型、测试脚本、JSON 报告、截图和源码差异；不包含 `node_modules`、构建缓存、录屏及浏览器 trace 压缩文件。正常启动不需要这些开发依赖；重新开发构建时执行 `npm ci`。
