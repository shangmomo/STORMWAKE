# STORMWAKE V71 · 化石谷远征 / 扫描美术升级

启动：完整解压，双击 `00_START_V71.cmd`。单人需 Python 3.10+ 与 WebGPU 浏览器，房主需 Node.js 22+。继承 V70 的现有海洋、船只、潜艇、洞穴与联机系统。

## 本包实装
- 港区三个服务建筑与公告厅使用已随 V70 提供但未用于这些建筑的 Poly Haven CC0 扫描家具及 PBR 木材；新网格复用原贴图数组，完成时才隐藏 V70 视觉回退网格，碰撞保持 V70 已验证布局。柜台、双货架、两种木箱、工具箱、砧板、灯具使用真实来源模型。房屋整体结构仍为程序化，不是完整第三方房屋模型。
- 沉岩洞侧面六件真实扫描补给道具；北部化石谷三处勘测站和六个木箱、三个灯具（使用同一套本地资产）。
- 击败荒潮船长后回港，在公告板接取北部勘测；调查三个标记站、回港提交，记录去重、持久化、一次性 160 金币。未安装暴龙时同样能完成任务。
- 陆上普通怪物、灯塔守卫和野生动物的转向改为限速；部分敌人归巢；野生动物加减速。攻击动画在蓄力阶段启动，按估计的接触时点调节播放速度；未做逐帧实机校准。

## 可选暴龙实验（不是本包已验收内容）
本次无法从外部下载模型。已经编写了 `RexBrain.js`、`RexEncounter.js` 和可选资产安装器。官方资源：
https://animalanimator.com/free-3d-animated-t-rex-reference/

来源声明：AnimalAnimator.com，CC BY 4.0。官方页面列出 84 关节、约 38k 三角面、四个动作 Idle/Walk/Run/Attack。双击 `00_INSTALL_TREX_V71.cmd` 可尝试从官方服务器获取，验证 GLB 格式、骨骼、动作、压缩扩展兼容性、文件 SHA256 并安装。无需安装第三方脚本，不影响主游戏启动；也支持 `python tools/install_v71_rex.py --local 官方下载的.glb`。

如果模型通过本机加载及骨骼名称校准，且完成北部勘测并返港提交，单人模式进入化石谷才会启用实验性暴龙。它有独立领地、限速转向、加减速、蓄力咬击、收招、局部骨骼碰撞与奖励。实际原始 GLB 尚未拿到，模型适配、骨骼方向、咬击帧、实际画面均未实测；如加载被拒绝不会显示虚假替代模型。联机暂不启用该实验。哥斯拉式泰坦未实装。
