# STORMWAKE V60 · 可运行完整源码包（阶段修复交付）

**请注意：这不是已经达到《盗贼之海》品质、完全无穿模的正式版。** V60 已实装可核查的船舶物理、干舱渲染、交互、分舱进水和联机货物修复，并通过 Node/WebSocket 回归；由于当前环境不允许浏览器加载本地游戏页面，**尚未完成 WebGPU 真实游玩与视觉验收**。不要将此版本标记成 3A 级品质或全部设计闭环已验收。

## 启动（无需先安装 npm 包）

Windows：解压整个 ZIP，双击 `00_START_STORMWAKE_V60.cmd`，选择单人、多人创建或加入。需要 Python 3.10+、支持 WebGPU 的新版 Chrome/Edge，创建多人房间另需 Node.js 22+。加入者在自己电脑上也运行本地游戏，连接房主 `局域网IPv4:5174`；房主 Windows 防火墙允许 TCP 5174。**双击程序必须保持运行**，关闭终端会关闭本地游戏服务器。

Python 命令（Windows/macOS/Linux）：

```
python start_v60.py --mode solo
python start_v60.py --mode host
python start_v60.py --mode join --room 192.168.1.20:5174
```

运行模式选择窗口需要桌面图形环境；命令行 `--mode` 可绕过选择窗口。若希望自行打开浏览器，增加 `--no-browser`，访问终端打印出的本机 URL。单人模式无需 Node 依赖。

## 与 V58 相比的实装变更

- 一组可交互锚绞盘、四个独立占位把手与真实连续 W/S 收放锚；调整 E 交互优先级，避免望远镜架抢焦点。
- 物理海底锚链：按海底水深判断触底，浅水绷紧/拖锚、深水未触底；锚链力作用于物理积分而不是强制直接修改速度，船只复位清理旧锚点。
- 干舱不再用相机状态关闭整个世界海洋；保留船局部水面裁剪；三舱段独立进水、慢速互通和舀水；船舱真实积水几何按位置与进水量显示。
- 网络里同步三舱段水位和锚链状态；修复客户端重复重建破口对象导致的 ID/比例问题。
- 多人藏宝箱在后甲板、船长室或下层货舱可拾取、存入、再取出；服务器验证甲板层/相对船位/距离，禁止越权取放和重复领取；断线会掉落手中箱子，供其他人继续取用。
- 修复 QA 对开场遮罩的不可靠判定、深海传送坐标与资源请求失败 URL 记录；增加 V60 专项与真实 WebSocket 用例。
- 保留原始完整船模、海岛、海怪、天候、UI、任务和资产；没有把原荷兰船换成不匹配的替代品。
