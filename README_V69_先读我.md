# STORMWAKE V69 · 潜艇控制 / 全帆 / 舱顶 / 三维巨兽

完整独立游戏包，保留 V68 的资源、原游戏、任务、装备和联机。解压到新目录，Windows 双击 `00_START_V69.cmd`。单人需 Python 3.10+ 和支持 WebGPU 的 Chrome/Edge；联机房主另需 Node.js 22+，队友均需使用相同 V69。无需 npm 安装即可正常使用原离线启动器。非 Windows 可在目录运行 `python start_v69.py --mode solo`。

## 操作与改动
- 深海魔鲸号：V 切换舱内、潜望镜、外部视角；X 回正；HUD 有水平/垂直独立反转按钮，灵敏度低/中/高共同作用于舱内和外部。设置自动保存。默认鼠标右/下对应屏幕右/下；鼠标移动解除自动锁定，不驱动潜艇。舱内 E 使用岗位，W/S/A/D 驾驶或行走，Space 上浮，Q/Ctrl 下潜，N 停车，原武器快捷键保留。武器使用当前视角射线方向（锁定时仍指向目标）。
- 荷兰帆船：四片原始布帆保留，按主帆、前帆两组控制，双面材质、独立按各自帆桁收展、帆角随调帆输入变化；帆装损坏的显示与受风面积同步。W 请求 AI 起锚/展开两组帆，S 请求收帆；AI 分别前往实际帆索，尊重玩家占用。各帆片仍分为两个操作组，并非四个独立岗位。风帆不使用昂贵的实时布料模拟。
- 船长室：修复原舱顶可见舱口盖未进入碰撞 BVH 的问题；封闭盖覆盖实际孔洞，足底扫掠支撑防止下落穿越屋顶，保留船长室真实门、楼梯和货舱开启通道。
- 四种海上巨兽：独立深度、巡游振幅、加速度、角速度、侧倾及俯仰，真实三维巡游，追击时上浮到攻击深度、间歇下潜环绕，按距离释放攻击；海床及浅滩前方探测。网络由房主服务端同步三维位置和姿态。原有技能、皮肤/骨骼系统保留。海神利维坦使用更慢的转弯限制、海床前视及联机姿态插值。

## 验收边界
`npm run test:v69` 为新增专项和历史回归入口，详见 `qa/V69-*.log`。新增测试使用实际 GLB 和碰撞 BVH、相机投影、AI 运动与网络序列化。当前环境浏览器导航被 ERR_BLOCKED_BY_ADMINISTRATOR 拒绝，无法完成真实 WebGPU 画面、极端风浪视觉、不同电脑多人实机、FPS 和长时间手感验收；本版不是已通过全部实机验收的版本。四种海怪有海床和浅滩前视，但没有全场生物相互避让、真实流体、所有骨骼碰撞和任意海域潜艇跨场景统一追猎。原自研 WebGPU/WGSL 路线保留，未迁移到官方 Three.js/TSL。历史即时攻击用例明确初始化浅水攻击状态，避免将新的深水巡游错误视为回归。
