# STORMWAKE V52 —— 原 Dutch Ship 门洞几何重建、船长室真实通行、自动昼夜灯

## 本次交付的边界

本工程在 V51 完整项目基础上直接修改，**保留原船主体**、桅杆、船帆、甲板纹理、原材质和 UV；未另外创建一套伪装成原船的外壳。船长室仍使用已在 V50 中引入的 TheMadraver Captain's Quarters 授权模型（CC BY 4.0），原船 Dutch Ship Medium 为 CC0。**二者不是同一原生模型，不能混称。**

本次交付重点是让“原模型小门不能供人通过、船舱无法正常下去、夜间灯要手动开”的三个问题进入可操作、可检查的状态，不声称达到《盗贼之海》全部功能或通过真实 WebGPU 全场景零穿模验收。

## 代码实际修改

1. **源船门洞是实心网格修改，不是盖一个门。** `tools/build_v52_passable_dutch_door.py` 从 V50 Dutch Ship GLB 中对原尾部隔舱壁的三角面进行矩形多边形裁切，保留开口周围边框的原材质、法线、UV；原有 **68 个**与开口相交的三角面被重裁/剔除，**80 个**新分割顶点产生可观察的真实洞口。新模型 `public/models/stormwake_v52/dutch_ship_passable.glb`。原 Rigging/Sails 顶点数据和贴图保留。
2. **门板同样来自原船。** 用 V50 原门板的 2 个三角面（4 个原顶点，保留它们的法线和 UV），在原枢轴上等比例附近放大，形成约 **1.14m × 1.09m** 的下层门洞。并非新构造的叠加门皮。门 `E` 开/关，只有完全旋转离开后才允许角色穿过，关门阻挡。
3. **角色真实通行。** 原船门比成年角色矮，采用小型角色比例：甲板站立碰撞高 **0.96m**，通过低门时自动降低到 **0.77m**，第一人称视点跟随下降；原先“只缩小了船员显示，却仍保留 1.75m 碰撞体”的不一致已消除。第三人称船员可视比例同步缩为原比例的 0.58 倍。陆地玩家仍保留之前的陆地身高与物理，避免破坏岛上楼梯和交互。
4. **原船体隔舱壁真正阻挡角色。** 在 `src/ship/HeritageDoorPhysics.js` 用前后坐标的扫掠测试判断是否穿越墙平面；房间外墙不再因为缺少程序碰撞器而可穿过。高层角色可走旧版原梯路线，低层进入须门真正打开。
5. **下舱真实舱口。** 继承 V50 源模型已经开出的甲板洞，不额外放一个假盖板；V51 会在下落到特定高度后把洞误判为地板，V52 改为**无论角色高度如何，开口范围始终没有甲板碰撞**。船长室原家具的 9 个碰撞体仍有效，原房间海图可查看。上/下梯采用同一船体局部坐标，避免漂移。舱内可自由移动，触发 `C` 或 `E` 在舱口上下梯。
6. **门口进入下层空间。** 修复“无采样地板就一律禁止移动”的旧逻辑。原门后侧是尾楼甲板下方空间，角色可以穿过门并在重力下进入下面的船长室；存在可由舱口梯返回上层的路线。**注意：从下方通过门本身上行没有单独作者原生楼梯，推荐用舱口梯返回。** 并非伪称原模型自带全套双向楼梯。
7. **船灯自动昼夜变化**。移除船灯的 `E` 手动切换交互；直接复用游戏世界 `App.settings.timeOfDay` → `G.night` → `LocalLights` 的统一黄昏/夜间照明曲线。入夜渐亮、早上渐灭，随船体运动；不新增虚构灯笼外壳。手持提灯操作保留。
8. **锚同步真实功能。** 不再让甲板锚摆设永远不动。**复用项目中已经下载的 Quaternius CC0 锚资源**（非 Dutch Ship 原装网格），在船艏舷外升降绑定到真实 `stations.anchorDown`，舵轮/自动停泊/联网锚状态由原有系统继续管理。因源 Dutch GLB 无独立锚对象，不能谎称从原船模型拆出了锚。
9. **船体稳定与移动**继承 V51 的横摇阻尼、原甲板表面采样修正、外壳重影隐藏和瞭望台返回修复，未重写稳定的航行动力系统。

## 启动与控制

- **Windows**：解压后双击 `START_STORMWAKE_V52.cmd`（需要安装 Python 3.10 或更新版本）。默认浏览器 URL `http://127.0.0.1:5173/?stormwake=1&heritageShip=1`；建议 Chrome/Edge 且支持 WebGPU。
- 也可运行：`python start_v52.py`。
- **E**：靠近原尾楼低门开/关；门必须完全打开后才穿过；门洞自动低头，无需额外按键。
- **C/E**：站在尾楼真实舱口中心时进入/离开船长室；**C+W / C+S**：按原有设定抓梯、上下原桅杆梯；原船尾楼隔舱壁梯 `C`，`W/S` 上下。
- 船灯**不需要按键**：利用原游戏自动时间周期；如需快速查看可以通过原有 Time of Day 选项设置白天和深夜。角色手持灯仍用原工具操作键。
- **锚**：靠近锚绞盘进入既有控制站后操作 E；老版自动航行系统也会决定抛起锚。

## 验收结果与不声称事项

| 检查 | 本次结果 |
| --- | --- |
| 新源网格 GLB 完整性、贴图/材质、门洞开孔、原门板 UV | 9 项 V52 专项检查通过，包括真实切面采样验证 |
| 完整历史 V51→V39 回归链 | 通过（见 `test/stormwake-v52-rebuilt-cabin.mjs`、`test/stormwake-v51-original-ship.mjs`） |
| 原舱口上下完整往返及低位碰撞 | 自动化路径模拟通过 |
| 自动昼夜灯与手动开关剔除 | 源代码逻辑和光源绑定测试通过 |
| 真正浏览器 WebGPU 画面逐项运行与场景目测 | **环境没有完成**，不能保证零穿模 |

原 Dutch Ship GLB 没有**独立可驾驶的小船**节点。以前项目中虽包含另一艘 Quaternius 小船资源，但它是单独的船，不是 Dutch Ship 原有可释放的小艇；**本轮未将它伪装成来源于原船的可驾驶小船。** 要达到小艇从船体起吊、漂浮、划行、再回收，需要一个独立的船只物理与交互系统以及玩家视角切换；当前 ZIP 不宣称该功能已完成。

以上测试不能替代人工 WebGPU 全流程：建议依次验收正反向门板开闭、前甲板走进低门的低头碰撞、从舱口进入/返回、舱内九处家具、20:00/01:00/08:00 灯光、近船首锚升降、船头跳跃、瞭望台往返和强风横摇。
