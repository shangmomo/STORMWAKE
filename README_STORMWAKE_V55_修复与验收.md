# STORMWAKE V55：船只与航行专项修复 / 验收说明

## 运行

1. **Windows：双击 `START_STORMWAKE_V55.cmd`**，进入单人、创建多人房间、加入多人房间的选择窗口。
2. **单人**：仅需 Python 3.10+ 与支持 WebGPU 的新版 Edge/Chrome。浏览器在本机 `127.0.0.1:5173` 打开。
3. **多人房主**：还需 Node.js 22+。创建房间会启动 WebSocket 服务器，监听 TCP **5174**；请允许此端口通过 Windows 防火墙。多人上限仍为四人。
4. **多人加入**：其他电脑也解压完整工程、运行同一个启动器，选择“多人·加入房间”，填房主的 **局域网 IPv4:5174**（例如 `192.168.1.20:5174`）。浏览器在玩家自己电脑的 localhost 启动，跨设备连接房主联机服务器。仅适用于可互通的同一局域网；公网穿透不在此包实现范围。
5. 可用命令行：`python start_v55.py --mode solo`、`python start_v55.py --mode host`、`python start_v55.py --mode join --room 192.168.1.20:5174`。均支持 `--no-browser` 和 `--port`。

**启动失败**：命令行运行 `python start_v55.py --mode solo` 可以看到异常。启动器需要系统 Python 的 Tkinter 图形组件；Windows 正式版 Python 通常自带。避免用不支持 WebGPU 的浏览器或旧显卡驱动。

## 游戏内重点操作

- 开局先在**陆地村庄**，向码头走，大船应在固定系泊位置，不再直接出生船上。
- 船侧两处前后绳梯（左右舷共四处），靠近绳梯的海面/码头位置按 `E`、`Space`（游泳接近也支持 `W`）攀登；在甲板顶的绳梯口按 `C` 可沿绳梯下行。离开船后会优先在靠港位置落到岸边，否则进入水中。
- 锚机站位按 `E` 操作，各岗位按 `W` 起锚、`S` 下锚，四名玩家可分占四个锚岗位一起用力；锚链的真实状态以 `anchorTravel` 为准，不能只看外观。
- `Z` 打开航海图，不必点击原有 1–7 号航点，**直接点击图上空白海域**即可指定新坐标。点在陆地则自动解析为附近可航行水域。AI 会在有人登船且航线可通时按路线导航；高浪或狭航道仍可能造成物理偏差。
- 联机时由房主同步大船物理状态和站位，不要同时用不同版本的脚本开房间。

## 测试事实和未解决的验收风险

**已通过**：`npm run test:v55`，包含 V55 新增六组逻辑/联机回归 + 原 V54 模块及多条真实 TCP WebSocket 集成测试；`node --check` 以及受影响 ES module 的导入检查。`start_v55.py` 已在单人、房主、加入模式做过进程启动/HTTP JS 与 GLB 路径可达性检查；房主后台多人服务 5174 的 HTTP 状态接口可访问。

**环境限制（必须如实区分）**：本环境中的 Chromium 自动浏览器因 `ERR_BLOCKED_BY_ADMINISTRATOR` 无法访问本地预览，未能完成显卡 WebGPU 场景运行与自由行走，因此不应把本次修改解释为已经逐一确认视觉碰撞“绝无穿模”、不同客户端真实人机联机稳定、Boss 动画达到 3A 水平。这些需要在你自己的 WebGPU 机器进行实机联测。工程既有 `npm test` 中的无头引擎用例还依赖未安装的 `webgpu` 包，故该**通用套件未全量通过**；与其不同，`npm run test:v55` 已通过。

**设计局限**：船舱海水现使用“封闭船舱禁用室外海面渲染”加船体位置遮挡实现，解决了主要的水平海水面穿舱来源，可能暂时看不到某些舷窗外的海面。真正“舷窗外有海水而室内完全不漏”的方案还需要舱体 SDF/模板缓冲区按体积排水及逐舱室遮挡验收。锚链是与权威机械状态联动的视觉链节，暂未实现完整钢链关节动力学或链条与海底的可解算碰撞。AI 避障依据静态地形水深，不包含实时船舶避碰与动态海浪预测。

## 对照验收建议

1. 陆地出生后沿村路走到码头，核对船与栈桥没有重叠/落空。
2. 在船静止时分别从码头、左右舷落水位置登船；行船时落水重新抓梯；从船舷按 `C` 下行，确认没有瞬移卡死。
3. 单人转绞盘验证锚降到位/升起；四人各操作一个位置，观察轴转动与速度加速、单人退出不抢占他人状态。
4. 进入下层货舱/船长室，绕靠近水面的每个墙角、窗口转动镜头；检查船外海面重新显示，漏水数值只受真正破损系统控制。
5. 海图设近岸、远海、岛屿背面三个任意目标；有人登船且非人工舵手占岗时观察 AI 逐点绕岛并最终停靠。
6. 双机加入 LAN 房间，检查随机航点和船只位置/方向、四人锚岗位、退出重连和新加入者同步。
7. 登陆接近陆地 Boss，近远视角观察是否隐身、浮空、足底穿地，验证死亡后行为和刷新。

所有新增功能为基于上传的 V54 源码增量修改，不需要覆盖外部存档即可启动。本包保留原工程其余资源及 `LICENSE/CREDITS.md`。
