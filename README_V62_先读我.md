# STORMWAKE V62

运行 `00_START_V62.cmd`，选择单人、创建房间或加入房间。需要 Python；多人房主还需要 Node.js 22+。使用支持 WebGPU 的 Edge/Chrome。V60、V61 原包未覆盖。

## 本轮实际改动

- 在原荷兰船模型上开通前后楼梯孔，安装可见实木阶梯和扶手；改用脚底支撑与胶囊抬步，不要求按 C 或跳跃上普通楼梯。下楼反复卡住的凸起金属条已嵌平。
- 修复 Kenney 设备 GLB 丢失外部色板的问题。8 个 CC0 派生模型内嵌原色板；锚先独立安装，火炮资源错误不再跳过船锚。
- 可见实体锚位于船首舷外，朝向沿舷侧；锚链、海床、受力和多人快照共用状态，替换原先固定 4.35 米的显示。浅水抓底，深于锚链长度时不抓底；拉力作用于船首并产生力矩。
- 3 个确定性移动水龙卷，共用位置、体积密度和受力场，替换单个半透明漏斗。低云体积、区域海雾、雨、闪电和距离延迟雷声接入世界。
- 幽灵舰队使用同一 FFT 海面查询；位置、血量、帆损、射击冷却等由房主快照同步，房主交接保留。击沉掉实体漂浮战利品，允许游泳拾取、搬到货舱、回港向商人出售；服务器防止重复发奖。
- 夜间月光、环境光和曝光提高可读性。

## 怎么体验

普通楼梯用 WASD；货舱梯仍按 E/C，桅杆梯按 C+W。绞盘 E 操作，按住 W 收锚、S 放锚，E 离岗。前往航海图中的幽焰舰队、水龙卷海域。击沉舰船后游近漂浮箱按 E 拾取，抱回船上实际货位存放，再回海风镇商人处出售。

## 验收和边界

详细证据、失败试次与设计规格对照见 `docs/V62_ACCEPTANCE.md` 和 `qa`。截图只能证明所拍位置，帧率上限 30 不代表所有硬件都稳定 30。

这不是“全部设计文档已做完”或“零 bug”版本。五类全新任务、完整巨兽接触/抓船、成年角色尺度与 IK、潜艇无切场景闭环等仍有未完成部分，逐项记录于验收文档。现有功能和本轮新增内容不混称为完整实现。
