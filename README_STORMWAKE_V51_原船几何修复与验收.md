# STORMWAKE V51 · 原船网格优先修复版

## 版本目标

基于用户上传的 V50 完整项目进行修改。核心原则：保留 Dutch Ship Medium 原船的船体、甲板、桅杆、船舱外壳材质和 UV；不再自行搭造一整套替代船体、船长室门或木甲板。船长室仍使用 V50 已安装并保留署名许可的 TheMadraver Captain's Quarters 素材，而不是伪称其属于 Dutch Ship 原船。

## 已完成的源代码修改

1. **原始门板开合**：新增 `public/models/stormwake_v51/dutch_ship_operable.glb`。从 V50 Dutch Ship 的 hull 网格抽取了源门板的 **两张三角面**，保留原始顶点属性、材质、UV、贴图和全体其他三角面，并在门边增加一个骨架式旋转枢轴。关闭状态可恢复两张三角面在原船中的精确位置，打开时只有原门板转动，而非在门表面新增另一扇门。船尾靠近原门处 `E` 开/关；门角度平滑变更。源码：`tools/build_v51_source_door.py`、`src/ship/HeritageAssetRig.js`、`src/voyage/VoyageM1.js`。
2. **舱口与船长室通行**：修正原舱口梯上/下梯终点 x 坐标不一致；取消自建盖板可见性，并移除其留下的透明碰撞地板。现在舱口是真实的模型开口，角色可以用 `C`/上下梯互动，也可从开口自然下落进入底舱。保留船长室家具的 9 处碰撞体，避免桌椅、床铺任意穿过。
3. **使用原船后舱隔墙梯**：根据 Dutch Ship 源网格位置定位了尾楼隔墙右侧梯（约 x=1.03、z=-6.62），在其上下方按 `C` 抓梯、`W/S` 双向连续攀爬，不用瞬移或再加同位置替代楼梯。
4. **桅杆瞭望台返程**：修复此前只能在底部抓梯的判断。登顶后使用 `C+S` 重新抓梯，`S` 下行；爬梯坐标保持与船同一刚体参考系。
5. **船员比例和寻路**：对 22m 大船取消旧艇比例放大带来的船员过大情况，额外缩小 24%；让船员的跨层路线经由尾楼原梯而不是穿过隔墙。
6. **船头甲板通行**：优化从原网格离线采样的可走表面邻域及步高阈值，减少可落脚三角面被栅格采样排除导致的卡住。仍只承认原船几何上确有支撑的地面，不补不可见平面。
7. **重影与物理**：旧 8m 程序船外壳、舵、轮等过时可见件隐藏；对 Dutch 原船跳过旧形状拉伸的水面深度遮罩，保留 V50 原有的船体局部水面剔除逻辑；降低帆船重心、增加横摇阻尼/惯量，缓解普通海况随意翻船。
8. **灯光交互**：在源船尾部、下舱和船头区域的已有位置绑定本地灯光，靠近船尾部可 `E` 关/开光照，不新增灯笼外观模型。灯具几何本身没有提供独立的 glTF 节点，所以目前只是光照层面可控。

## 操作

- Windows 双击 `START_STORMWAKE_V51.cmd`；或者运行 `python start_v51.py`。需要 Python 3；浏览器需要支持 WebGPU。
- 登录/载入时 URL 包含 `?stormwake=1&heritageShip=1`，采用 Dutch Ship Medium 模型。
- 尾楼原门附近：`E` 开/关门板；尾楼灯控制：`E`，以靠近时提示为准。
- 船身右后隔舱壁原梯：`C` 抓梯，`W/S` 上/下；靠近桅杆 `C+W` 上梯；瞭望台 `C+S` 重新抓梯下行。
- 原甲板开口：`C` 进入船长室，底舱 `C` 爬回甲板（或使用游戏提示 `E` 交互）。
- 船锚、大炮、货物、航行交互仍保留 V50 既有键位与任务系统。

## 必须如实说明的源码限制

1. 原 Dutch Ship GLB **仅有三个单体原始主网格** `hull`、`rigging`、`sails`。没有可直接旋转的 `anchor`、`lantern`、`dinghy`、`door`、`wheel` 等独立节点。本版完成的是有明确源面片可辨识的原始小门，而不是原 GLB 原本就包含完善的功能控制器。
2. 从原源面定位出的舱门板约 **0.60m 宽、0.75m 高**，不是可以自然通过一个约 1.5m 高游戏人物的标准舱门。尽管现在可开合，这扇门**不能承诺玩家可以站立穿过**。扩大通行需要对门洞周围原船几何进行**真实拓扑重建**并重新做碰撞；该操作尚未完成，不能拿一个新自建大门欺骗视觉。
3. 旧版船首锚的真实收放逻辑、载具逻辑和人物互动仍部分依赖之前引入的单独资源或程序装配。**没有证明原船网格包含可直接使用的原生小船、可分离船锚和所有灯具**，因此这些不能标成“原模型功能已全部恢复”。
4. 原船艏部、甲板复杂交叉处仍需人工走位测视角与碰撞，舱内碰撞仍以 V50 边界和家具简化盒为基础。局部材质双面显示并不等于完整闭合、完整防穿模的模型拓扑。
5. 目前不是《盗贼之海》的等价复刻，也未通过全气象、全交互、多人及 3A 画面测试。此 ZIP 是基于实际改动与自动测试的 **V51 修复工程**，不是认证“零 bug 成品”。

## 建议的交付后人工验收顺序

1. 贴近船尾原小门，开/关：确认门板没有重叠残留、不穿透横梁。
2. 从船长室外真实舱口 `C` 入舱、拿放货物、上下梯返回；留意家具角落、舱口边缘和外海水面。
3. 从后甲板沿原隔墙梯上尾楼、下楼；从桅杆到瞭望台再下降。
4. 从船中部跑跳至艏部（左右舷各一次），测试狭窄走道与视角无透视重影。
5. 依次开灯、关灯、抛锚、起锚、手动航行、船员控制炮位；在常规与风暴海况观察横摇及 HUD。
6. 若确需原生小船 / 能让角色通过的原厂大门，必须补充带独立物体、真实内舱和拓扑的源船资产，或授权对原船网格做可检查的拓扑重构。
