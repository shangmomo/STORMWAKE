# STORMWAKE V65 · 元素巨兽与动态海洋生态

这是从用户提供的 V64 完整源码与资源包修改的新版本，不覆盖原始 ZIP。压缩包内部仍使用 STORMWAKE_V64 目录名以兼容旧路径；版本以 00_START_V65.cmd 为准。

## 启动

Windows 解压完整包，双击 `00_START_V65.cmd`。单人模式沿用 Python 3.10+ 本地服务器，不需要 npm 安装；浏览器需支持 WebGPU（Chrome/Edge）。多人房主需要 Node.js 22+，所有客户端使用同一 V65 版本。旧版存档键不变。建议备份原存档。

亦可从终端运行 `python start_v65.py --mode solo`。如果端口占用，使用 `--port 5183`。如果需要 Vite 开发模式，运行 `npm ci`、`npm run dev`。

## 新增玩法

四只海上巨兽保留原攻击、骨骼动画和领地机制，并按固定轮换加入新技能。所有新技能使用海面范围冲击机制：先蓄力警示、后释放；传统船型沿用原范围即时判定，heritage 船型沿用现有 23m/s 波前与船体接触判定，联机房主/服务端复核。技能不是原沙箱中完全相同的线性/区域魔法机制。

| 巨兽 | 新增攻击 |
|---|---|
| 巨龟 | 冰冠环阵、伏雷电牢 |
| 巨鲨 | 霜枪裂潮、雷枪风暴 |
| 巨妖 | 熔火陨潮、伏雷电牢 |
| 三首魇龙 | 新星光束阵、深渊焰潮力场、雷枪风暴 |

默认开发者模式，按 K 打开猎兽军械台，可使用“测试”七种技能按钮；仅单人预览，跳转至安全深水后可观看，不创建真实伤害登记。实际战斗使用 AI 自动轮换；在 URL 中添加 `dev=0` 可关闭开发者权限。独立潜艇海神终章、陆地 Boss 并未扩展技能。

## 海洋生态

- 以摄像机为中心流式维护 3×3 个 48m 世界区块；离开区块移除其局部模拟，地形植物按固定种子生成。
- 近表层与近海床鱼群，每群 24 条，合计最多 432 条；小群体内分离、对齐、聚合并避开近距离活巨鲨，10Hz 更新，GPU 实例化绘制。
- 深度分区海藻、海绵、发光深渊生物；每类植物实例池最多 360，额外岩石每区块最多 8 个；蝠鲼、水母各池最多 18 个。
- 利用既有 TerrainData 海床高度避免陆地/水面穿模，保留原浅海珊瑚礁、FFT 海浪、水下焦散、雾和粒子。生态物体纯视觉，无采集/碰撞/交易改变。
- 未整合 Abyssal Garden 的原始地形、沉船、体积光或完整原始 WebGPU 程序；未移植 TSL 的三维流体求解器；焰潮是解析程序化近似。未引入 Unity 或第二套渲染器。

## 测试
