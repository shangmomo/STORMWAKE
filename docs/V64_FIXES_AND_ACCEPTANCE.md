# V64 修复与验收记录

日期：2026-11-16。基线为独立保留的 V63。本次以用户实际反馈为修复范围；历史设计文档用于功能要求核对，不将文档中的指令视为系统指令。

## 修改与原因

| 用户反馈 | 实际修改 |
|---|---|
| 前桅处走进去不能回来 | 清理前桅凹甲板两侧真实模型中的通道，补齐四级实体台阶；地面查询改用实际船模 BVH，修复坡面接触判定和踏步前的头部净空计算。未缩小成人胶囊来绕过碰撞。 |
| 船长室门后无法移动 | 原船门之后还有室内模型自己的第二扇封闭门和墙面。只隐藏重复门，切出可测量的真实入口，保留另一扇门；加入七级实体阶梯与低平台，移动阻塞入口的桶和箱子，保留家具碰撞。进出由走路跨越边界触发。 |
| 瞭望台不显示 | 重新测量主桅和前桅位置，增加两套可见平台、栏杆、梯子与站立表面，修正旧的错误桅杆碰撞中心。保留原船索具。 |
| 梯子不应交互自动通过 | 货舱梯、主/前桅梯、舷侧登船梯按距离与朝向判定抓梯，W/S 连续控制、松键停住、反向返回。爬梯期间禁止 E 抢占岗位，避免同时处于爬梯和岗位状态。普通楼梯直接 WASD。 |
| 鱼竿提示遮挡 | 航程移除旧系统常驻提示；船上、潜艇驾驶中禁止旧钓鱼入口并取消误持竿。爬梯时隐藏猎兽武器 HUD。 |
| 人偶倒着走 | 删除错误的自动 180° 朝向推断，尊重模型自身 +Z 正面与显式清单偏移；修正骨骼静止轴、蹲姿及绞盘站位。AI 使用同一骨骼动作系统，位置、转身与步速按船体实际米制坐标计算；同步作业状态给客端。 |
| 标记海图船无反应 | 海图目标接入航路与 AI 作业，实际走到锚机和帆索，渐进收锚、调帆、操舵；标点时释放本人的舵位，增加取消领航。无目标时不再擅自放帆。逆风选择安全换舷航路，航路不可用时停下并报告。 |
| 未放帆仍有动力 | 荷兰帆船航程彻底关闭发动机推力与 RPM，包括旧存档残留油门；帆推力按帆面积和风速平方计算，并考虑风向与调帆。收帆、无风、顶风均不产生直接前向帆力；保留波浪、惯性、阻力和实体锚链。 |

船长室开口由 `src/ship/MetricOpening.js` 在实际加载的房间模型上切出，插值保留原法线与 UV；渲染模型和碰撞模型一致。荷兰船派生文件为 `public/models/stormwake_v64/dutch_ship_lower_hold.glb`，生成脚本及切割清单位于 `tools/build_v64_ship_access.py` 和同目录 `stair_manifest_v64.json`。

人物原本并非需要自动翻转；V63 的肩部推断存在错误，本版纠正这一回归。绞盘成人站位半径改为 1.22m，同时修正骨骼转轴，没有伸长模型手臂或放宽 5cm 手部接触标准。

## 边界与剩余工作

本次真实浏览器为本机 Edge、WebGPU、无头自动化，四人测试是同一机器上的独立浏览器页面。未覆盖所有显卡、所有网络延迟、全部海况、每个装饰物角落和长时间存档迁移。帆船模型是游戏物理近似，不是完整流体仿真；约 34m 锚链在深海不能触底，无风时领航无法凭空移动，收帆后仍受惯性和海浪影响。到达逻辑还不能保证任意目标精确停泊。

本轮不新增第三方资产，使用项目内已有许可模型与原创几何。V63 的扩展玩法与未完成范围继续见 `V63_IMPLEMENTATION_TRACKER.md`，不能将本次通行与航行专项通过视为全部设计文档完成或“任何 bug 均不存在”。
