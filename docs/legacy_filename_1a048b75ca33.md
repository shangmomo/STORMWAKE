# 潮汐海岛 V26：海神关卡体验修订

## 为什么 V25 的深海看起来几乎全黑

- 默认海水光学系数是正常海洋用的：绿光总衰减系数约为 `0.075+0.018=0.093/m`。100 米处绿光透射率约 `0.009%`，灯光数值再大也难以辨认利维坦。
- V26 在**仅进入海神独立关卡**时通过 `frame.abyssVision` 降低光程衰减；离开时立即归零。以默认水质、100 米为例，绿色通道的透射率大约从 `0.009%` 提升为 `30%`。原本海面、岛屿水质参数与渲染逻辑保持不变。
- 增强 Nautilus 两侧探照灯（双灯亮度 52,000、有效范围 230 米）、船舱下方补光、海神发光补光（范围 320 米）、体积散射光束，同时提供很弱的蓝青色远景填充，以便读出轮廓。
- 深海视觉采用适合奇幻终章的可玩性曝光，**不是现实潜水摄影的严格光学还原**。

## 操作与界面

| 操作 | 功能 |
| --- | --- |
| W/S | 前进／后退，惯性加减速 |
| A/D | **左转／右转**，逐渐施加转向速度和船体倾斜 |
| Space / Ctrl | 上浮／下潜 |
| 鼠标左键或右键按住拖动 | 独立环视，不改变潜艇船体朝向 |
| Q/E、上下方向键 | 左右环视／上下调节镜头 |
| 滚轮 | 连续调整追随镜头距离 |
| X | 镜头回正 |
| V | 外部跟拍／潜望镜视角切换，平滑过渡 |
| L | 开关搜索灯 |
| C / R | 发射鱼雷／主动声呐 |
| 返回海面 | 退出终章关卡，保留角色之前的海面位置 |
| ⌂ 传送回主岛 | 退出关卡，然后连同船与角色传送到主岛港口附近的安全深水区 |

独立深海 HUD 替换了战斗时的普通主岛 HUD，顶部状态卡限制在约 535px 宽、底部的操作栏固定在视口底部；不会再叠在旧的钱包、天气和钓鱼条上。对屏幕高度较小和窄屏也做了样式适配。

## 海神利维坦运动

- 保留 Lebin Benny 雕塑、66 节真实蒙皮骨骼，以及项目创作的 `Swim/Charge/Attack` 三段 GLB 动画。
- 修正 V25 在 `charge` 状态优先匹配 `Attack` 的错误：现在 `Charge` 真正用于高速冲刺，`Attack` 用于蓄力，`Swim` 用于普通巡游。
- 转身使用角速度惯性，前进沿头部朝向，不会让整具身体横向滑动追踪目标。
- 冲刺开始后锁定主要攻击方向，体态俯仰、侧倾和动作片段统一平滑；战斗碰撞仍沿真实海神身轴与潜艇位置检测。

## 主岛真实回港

- 读取当前世界主岛港湾与实际地形水深，不会把船传送到沙滩或房屋中。
- 选定的首个可用港外水深约为 **8.74 米**（当前地图），坐标约 `(85.8, 114.5)`，紧靠主码头外侧。
- 通过原船体 `BoatController.teleportTo()` 复位旧水面采样与速度；角色同时就位，防止模型和碰撞位置分离。**锻造、战利品、Boss 击杀记录不重置。**

## 验证与限制

- `npm run test:v26` 包括 V26 新增的布局/输入/动画运动/光学模式与回港单元测试，以及 V25～V11 全部回归。
- 原美术文件和模型的作者/CC BY 4.0 署名仍保留在 `public/models/` 与 V25 文档中。
- 本次环境离线缺少 Vite 安装包，无法执行完整 WebGPU 浏览器图形验收；运行时请在自己的 Windows 浏览器实际检查灯束、镜头手感和帧率。如有实机截图，可继续针对亮度/色调做微调。

**启动：**Windows 双击 `START_WINDOWS.cmd`，或使用 `python run_windows.py`；首次运行需要 Node.js 并允许 npm 安装依赖。
