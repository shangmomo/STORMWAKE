# V85 晶岩地下远征

## 已实装
- 原矿井新增六处有限矿脉（铁矿6、铜矿6、晶石4），收起武器靠近按 E 三次，每次约0.48秒敲击动作；每次确认距离、遮挡及状态，离开或取消时不发放资源。采尽的模型消失，存档保留。镐为场景内程序化动画，不是已制作的角色全身骨骼动作。
- 地下湖新增三处真实湖底匣（347,-548；353,-553；350,-556），C 下潜、Space 上浮、近距离按 E 回收；必须处于游泳且水面以下。晶岩祭坛可调查，集齐后岸边 (373,-541) 的480HP晶岩巨蛇现身；使用原战斗武器、蓄力预警、格挡、闪避和收招反击，半血追加突刺，首次击败获得300金币及晶石3。巨蛇为岸边定点程序化分节模型，不是水中移动或导入的真实骨骼生物。
- 矿袋 HUD、遗物计数、巨蛇血量；现有铁匠铺提供材料强化及一键出售，保留金币强化。铁矿/铜矿/晶石/遗物单价12/9/35/60。强化消耗真实矿石，金币与等级、矿袋、一次性采集状态同存档原子提交，失败回滚。原有矿井调查、升降机和岩湖潜伏者保留。
- 单人经济结算；联机保留场景，不启用新资源结算或巨蛇战斗。
