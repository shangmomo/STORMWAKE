# STORMWAKE V67 操作与 HUD 专项修复

## 操作规范
|上下文|按键|行为|
|---|---|---|
|陆地/甲板自由行走|1/2/3|直接装备短刃/长矛/钓竿（含数字小键盘）|
|陆地/甲板自由行走|0/4/5/6/7/8|空手/提灯/望远镜/木板/水桶/铁铲；实物补给仍需获取|
|持个人武器|左键/J、K、Q、右键|轻击、重击、闪避、格挡|
|持个人武器|Z|收起武器；随后按 R 切换钓鱼姿态|
|空手、陆地/甲板|R|钓鱼竿取出/收回；左键蓄力、释放抛竿|
|甲板海兽武器（未持个人武器）|T、F|切换海兽武器、开火/望远镜|
|自由活动|P、F2、F3、F4|任务日志、海图、猎兽军械台、伙伴|
|航海岗位|F2|海图，关闭后恢复输入|
|任意游戏场景|F7、F8|纯净/恢复；循环精简→纯净→完整|
|非潜艇且非岗位|H、Shift+P|设置、原拍照模式|
|潜艇|W/S、A/D、Space、Q/Ctrl|前后、转向、上浮、下潜（驾驶岗位）|
|潜艇|E、V、方向键|舱内岗位、视角、外部观察方向|
|潜艇岗位|C/G/T、R/Z、Y|鱼雷/鱼叉/深弹、声呐/防御、维修；联机按岗位权限|

## 实际改动
- 独立 ControlPolicy 管理上下文、快捷键所有权、对话和菜单隔离。数字武器不再被航海工具提前消费，连击恢复时切换排队。装备工具会退出战斗姿态，收起钓鱼竿；第三人称船员按当前武器显示，网络姿态接受长矛和钓竿。
- Input 忽略重复键、文本输入和浏览器组合键；允许 Ctrl 下潜，焦点丢失/菜单切换清除旧键鼠状态；菜单先于移动处理，避免关闭菜单同时攻击。
- 地面/甲板武器共享入口，甲板闪避；海怪触手/幽灵原接触机制保留，不等于重新实现多人陆地战斗伤害权威。
- HUD 三模式独立于相机与时间，默认精简，记忆模式。纯净隐藏游戏 HUD 而不隐藏任务、背包和捕获弹窗；按 F7/F8 恢复。潜艇中隐藏海面面板，精简减少说明文字。原先拍照模式保留为 Shift+P。
- 修复甲板钓鱼被禁止、弹窗期间抛竿、潜艇内武器瞄准与俯仰/横滚后的实际舱内视线不一致等问题。
- 启动入口为 00_START_V67.cmd，完整包无需旧版安装器。
