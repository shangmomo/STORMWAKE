# STORMWAKE V39 · Voyage Co-op M1 — 实施与验收

## 0. 完成范围与限制

本版本严格依据 `STORMWAKE_WebGPU_设计与制作执行手册.md` 制作 **M1**。保留 Tidewater V38 自研 WebGPU/WGSL 引擎、FFT 海浪、天空、后期管线和 V30+ 深潜入口；没有迁移 Unity/Unreal，也没有把凯洛、完整灯塔航程、PvP、Relay/TURN 等 M2/M3 功能塞入 M1。

**M1 主循环**：海风镇金潮告示板接任务 → E 登船甲板 → 占舵轮/帆索合作出港（单人由 AI 补岗）→ 灰苔岛地标附近按住 E 4 秒挖宝 → E 拾取宝箱（移动×0.55）→ 船内货舱 E 入舱 → 绕过/击沉 AI 炮艇 → 返港找金潮经纪人 E 售卖 → 120 潮币、1 金潮声望。

### 代码实现

- `src/ship/ShipStations.js`：九个岗位、同人单岗、占用互斥、真人驱逐空岗 AI、输入与开火冷却；
- `src/ship/StationSites.js`：船体局部坐标，随船移动、旋转；
- `src/ship/SailWind.js`：相对风向与风帆推力，保留 V38 原浮力积分与船体拖曳；
- `src/ship/ShipDamage.js`：完整性、进水、火灾、修理、灭火、沉船状态；
- `src/ship/CrewAI.js`：舵、主帆、右舷炮三名 AI，真人抢岗自动让位；
- `src/ship/EnemyShotgunBoat.js`：AI 炮艇巡逻、靠近接敌、舷炮伤害、低血量撤退和沉没；
- `src/voyage/{VoyageDefs,VoyageDirector,DigSite,Cargo,Broker,VoyageWorld,VoyageM1}.js`：任务目标、单次挖掘、可持宝箱、入舱、奖励去重、世界标识、炮弹、HUD；
- `src/interact/InteractionDirector.js`：同帧最高优先级 E 键候选仲裁；
- `src/net/ShipNetBridge.js` 与 `server/coopHub.js`：房主权威船体，岗位申请/释放/输入、状态同步、任务和货物广播、重复消息与奖励校验。

UI 在港口、甲板、挖点和售卖环节显示下一目标；语言根据游戏 locale 选择中文或英文。原生 WebGPU 引擎、现有角色、海洋材质和原先已授权的艺术资源未作不必要更换，未引入需要网络下载的新资产。

### 关键 bug 修复

1. **AI 锚地软锁**：接航程后只有实际有人登船才允许 AI 自动起锚；抵达停靠航点自动抛锚，锚位真人占用时 AI 不抢操作。
2. **远端操作丢边沿**：炮击点击、锚绞盘单击、灭火动作采用发送缓冲，避免落在 60 ms 网络节流间隔就丢失。
3. **非主机维修**：远端维修和灭火由房主统一结算，避免客户端各自减血/增血。
4. **挖掘漏洞**：服务端要求连续 4 秒进度流，松键、离开或超时重置；修复计时到 100% 但宝箱不出的浮点边界。
5. **帆位视觉同步**：其他船员看到相同缩放的帆布；船员共享主船，不再为每个登船同伴分配一艘不可见完整船。
6. **持箱位置**：可见宝箱跟随玩家坐标，而非固着在货舱标识。
7. **沉船货物**：本地沉船将船舱箱子转为海面可拾取世界物品；完整沉船渲染/重生留 M2。

## 1. 启动方式

**Windows 单机**：在解压目录运行 `python start_v38.py`；访问 `http://127.0.0.1:5173/?stormwake=1`。浏览器需支持 WebGPU；使用 `?stormwake=0` 可以切回 V38 的旧驾驶入口，老的深潜系统未删除。

**Windows 局域网房主**：`python run_v39_coop_windows.py`（要求 Python 3 和 Node.js 20+；不需要 npm install）。会在本机 5173 启动浏览器静态服务，在局域网 5174 启动原生 WebSocket Hub。房主打开程序显示的 localhost 地址。

**其他船员**：每台电脑自行运行 `python start_v38.py`，在各自浏览器打开 `http://127.0.0.1:5173/?stormwake=1&coop=1&room=房主局域网IP:5174`。不要在另一台电脑直接用房主的内网 HTTP 网页代替本机 localhost；这样不能保证 WebGPU 安全上下文。允许 Windows 防火墙放行房主 TCP 5174。

**Vite**（如果你本机已经安装开发依赖）：原 `npm run dev` 继续可用。

## 2. 按键表（占岗只读本岗位输入）

| 情况 | 输入 | 行为 |
|---|---|---|
| 步行 | WASD / Shift / 鼠标 | 移动、疾跑、镜头 |
| 岛上 | E | 公告板、拾起宝箱、经纪人；挖点处持续按住 E 4 秒 |
| 登船 | 靠近码头船 E | 进入可步行甲板；不直接全权驾驶 |
| 甲板 | 近舵/帆/炮/桶 E | 占岗；占岗后 E 离岗，Esc 也可离岗 |
| 舵轮 `helm` | A / D | 舵角；无人操舵缓慢回中 |
| 主帆/前帆 | W / S | 收放帆（保持当前帆位） |
| 锚绞盘 | E | 抛锚／起锚；Esc 离岗 |
| 左/右舷炮 | 鼠标左键 / R | 发射 / 装弹；不同炮位互斥 |
| 维修桶 | 按住鼠标左键 | 修补船体、止漏 |
| 水桶 | E | 扑灭火焰；Esc 离岗 |
| 搬运 | E | 拾箱 / 放入船舱；持箱减速 |
| 取消航程改动 | `?stormwake=0` | 回到旧 V38 主循环 |

## 3. 世界点与地图债务

港口告示板 `(48,-75)`，金潮经纪人 `(56,-71)`；灰苔登岸目标 `(-130,10)`，挖点 `(-176,-42)`；返航 `(~70,~37)`，敌方炮艇航路在灰苔外海。**本期灰苔岛采用大岛远侧已存在地形的“灰苔登岸区”，未修改地形生成器建立一座完全独立新岛**。这符合手册 §E 的 M1 允许路径，但必须在下一阶段专门完善离岸沙洲可达性。
