# Tidewater V31 · 陆地生态与《灯塔下的低语》

本版直接在 V30 完整工程上开发，未移除或替换原海岛、港口、住宅、钓鱼、商店、小汐、舰船、潜艇及深海海神系统。

## 一、运行方式

1. 解压完整工程 ZIP，进入最外层的 `Tidewater_V31` 文件夹。
2. Windows 在该目录执行 `python start_v31.py`；macOS/Linux 执行 `python3 start_v31.py`。
3. 安装 Node.js 20+ 与 Python 3，使用支持 WebGPU 的较新 Chrome/Edge。首次启动若不存在 `node_modules`，启动器将运行 `npm ci`。
4. 从海风镇出生地步行到附近的木制探险告示板，按 `E` 接取「灯塔下的低语」。

## 二、陆地操作（不会改变 V30 深渊潜艇控制）

| 操作 | 功能 |
|---|---|
| W/A/S/D | 第一人称步行，鼠标自由观察（继承原游戏） |
| Shift | 奔跑；Space | 跳跃 |
| E | 调查告示板、森林石碑、灯塔镜片，或与港口居民交谈 |
| Z | 拔出 / 收起潮纹短刃；拔刀时钓鱼竿自动收起，鼠标攻击不会触发钓鱼 |
| 左键或 J | 潮纹短刃轻击：12 体力、32 基础伤害、短冷却 |
| K | 重击：27 体力、58 基础伤害、较长冷却 |
| Q | 闪避：沿当前移动方向翻滚，不按移动键时后撤；花费 22 体力，带短暂无敌时间 |
| 按住鼠标右键 | 格挡：消耗体力，将一次敌人命中伤害降至约四分之一 |
| P | 折叠 / 展开右侧陆地冒险日志 |
| L | 游戏原有手电筒：可驱散失落水手幽影 |

原本的 `F` 自由相机、`T` 时间控制、`R` 钓鱼杆、海岛商店和深渊潜艇快捷键保留。战斗仅在玩家处于陆地步行模式时激活；开背包或商店面板时暂停陆地攻击输入。潜艇内部不受 Z/J/K/Q 系统影响。

## 三、已实际实现的内容

### 1. 陆地生态

- 密林狐狸、野猪、鹿：使用多部件原创低成本 3D 模型，具有休息、轻微活动、步行动画、玩家接近后逃离，以及潮蚀预警时受到惊吓等行为。
- 海风镇三名新居民：港口巡守阿岚、草药师米拉、前灯塔看守洛恩。白天各自工作，傍晚在镇里活动，夜间回家休息；玩家走近可按 E 交谈，居民会根据灯塔是否修复改变台词。
- 新增森林古代石碑与补给奖励、荧光路标、山路绕行路径以及夜间潮蚀光尘。
- 原有海鸟、沙滩螃蟹、居民商店、小汐与房屋系统完全保留。

### 2. 第一章：灯塔下的低语

1. **告示板**：按 E 接下调查，小汐切换跟随模式（之后仍可以通过她的原有控制 UI 调整模式）。
2. **翡翠密林**：沿发光石柱和日志方向/距离提示逐个寻找山路，途中有敌人、野生动物和隐藏石碑。
3. **森林石碑**：可选探索，提供三面反光镜顺序线索以及首次探索奖励。
4. **断崖灯塔**：三面镜片可通过 E 旋转到正确角度（从默认朝向分别旋转 2、1、3 次）。每次对准，真实 3D 光路连接灯塔。小汐若在第二面镜片附近会帮助固定角度；即使她暂时不在场，玩家仍能独立完成，保证不会软锁。
5. **守望者精英战**：三镜校准后唤醒，拥有横扫、震荡波、冲锋三种不同的攻击类型、红色范围预兆、受击硬直和半血后加速。
6. **结局**：击败守望者，灯塔重新点亮并奖励 250 金币；章节进度保存，可在下一次启动继续。

### 3. 陆地敌人及实际接触判定

- 潮蚀寄居兽：68 HP，防御型近战、较长出手前摇。
- 夜影猎犬：52 HP，移动更快、攻击蓄力时间短。
- 失落水手：92 HP，夜间/灯塔任务区域活动，会受手电筒影响而退避。
- 灯塔守望者：520 HP，具有三类循环招式和半血强化。
- 攻击碰撞判定同时检查**水平距离、攻击朝向与垂直高度**；近战不能隔着数层楼碰撞，也不能无视攻击范围直接扣血。
- 攻击前红色警戒环可见，命中是唯一瞬间事件，闪避无敌帧和格挡有各自的判定与资源成本。
- 玩家生命耗尽后由小汐救回海风镇，保留灯塔任务进度；通关奖励有持久唯一交易 ID，不能靠重新进游戏重复领取。

### 4. 海陆潮蚀事件

- 在灯塔未修复前，平静期、黄昏预警、20:00–04:00 侵袭期按现有游戏时钟自动变化。
- 当已完成第一次陆地战斗、接受过灯塔任务，并在侵袭时靠近海风镇，触发当日的**105 秒港口防御**：三只敌人分别从不同方向侵入。
- 全部击败奖励 75 金币；失败没有即时惩罚，可以在后续游戏日重试。
- 事件结束会将临时敌人从场景和 AI 列表移除，避免几天后越积越多。
- 灯塔修复后由常态夜间侵袭切换为「灯塔守夜」，原野危险区域仍可以探索。

## 四、实现重点与性能

- 自研 WGSL/WebGPU 引擎，不引入 Three.js 或 Unity 运行时。
- 新增陆地可见模型均由几何体组合生成；灯塔、镜片、石碑和路标使用合批的共享材质，居民/动物/敌人仅使用少量动态部件，降低 draw call。
- NPC、动物、怪物只在玩家附近可见，敌人远离玩家时不执行追击逻辑。灯塔模型在 GPU 预编译之前加入场景，避免玩家首次走入森林时因 Shader 编译导致明显卡顿。
- 与钓鱼、互动、乘船的键位按模式隔离；不修改深渊潜艇的车钟和方向舵逻辑。
- 存档使用单独的 `tidewater:land-expedition:v31` 本地键，旧版 V30 用户存档不会被覆盖。
- 复杂大型 AAA 场景、真实动作捕捉和完整配音**尚未实现**；当前是一段已集成到游戏的可玩陆地冒险章节及其扩展基础。

## 五、验证与已知边界

在有 Node.js 的项目目录运行：

```bash
npm run test:v31
npm run test:course
npm run test:harbor
npm run build
```

`test/stormwake-v31.mjs` 覆盖敌人状态机、战斗预兆和攻击类型、闪光灯驱避、存档兼容、光镜机关、小汐协助、灯塔 Boss、港口防御、居民时间表、原有钓鱼与角色控制的静态隔离。`test:v31` 还会调用 V30–V11 原有回归。

本环境没有可用于完整图形试玩的 WebGPU 浏览器，因此只能证明 CPU 逻辑、模型几何体构造与前端构建通过。镜头内武器大小、HUD 遮挡、地形实际通行感、灯塔夜间表现仍应由你在 Windows + 4090 电脑上实地试玩确认；发现问题后可以基于 V31 继续迭代。

## 六、建议试玩流程

1. 白天出生在海风镇，向附近木告示板走近，按 E 开始冒险，观察小汐是否跟随。
2. 按 P 查看任务日志；沿石柱前进，检查动物是否会逃跑。
3. 按 Z 拔刀，用 J/左键与 K 轻重攻击，并尝试用 Q 避开敌人的红色预兆，检查血量和体力条。
4. 在密林古代石碑按 E 读线索，然后依靠绕坡路标爬上灯塔。
5. **击败第一只密林敌人后、修复灯塔前**，可返回海风镇等待 20:00 后的潮蚀，体验限时港口防御；修复灯塔会驱散这类常态入侵。
6. 回到灯塔，按 E 旋转三面镜片，观察连接灯塔的光束；成功后挑战拥有三招的守望者。
7. 切换到原版海洋/潜艇游戏，验证船舶、深海武器和海神战斗没有被陆地章节改变。
