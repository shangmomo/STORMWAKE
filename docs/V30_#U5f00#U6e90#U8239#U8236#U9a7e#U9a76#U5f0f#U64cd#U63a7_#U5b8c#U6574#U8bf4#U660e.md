# Tidewater V30 — 船舶驾驶式潜艇控制（开源设计参考）

> 本版在 V29.1 完整工程上实现新的驾驶模块。没有替换原海岛、存档、港口、船只、潜艇或利维坦模型，也没有移除深渊武器或 Boss 战斗状态机。

## 开始体验

1. 将完整工程 ZIP 解压，打开最外层 `Tidewater_V30` 文件夹。
2. Windows 执行 `python start_v30.py`；macOS/Linux 执行 `python3 start_v30.py`。
3. 电脑需要 Node.js 20+、Python 3 与支持 WebGPU 的 Chrome/Edge，第一次启动自动安装 npm 依赖。
4. 点击浏览器游戏画面捕获指针，在军械锻造界面进入海神深渊。

## 默认操控（标准船舵）

| 输入 | 动作 | 与 V29.1 的关键差异 |
| --- | --- | --- |
| W | 车钟增加一档；按住会继续逐渐加档 | 松开 W，**目标航速保持** |
| S | 车钟减少一档；过零后倒车 | 负油门不需要持续按键 |
| A/D | 左右打舵 | **松开自动回中**，舵角渐变 |
| 鼠标 | 独立观察镜头 | **绝不改变船头朝向**，默认不自动回正 |
| N 或右上角「停」 | 将车钟拉到零位 | 明确的停车命令，不影响上浮快捷键 |
| Shift | 车钟已开时临时急速推进 | 最高仍为 116 m/s |
| Space / Ctrl | 上浮 / 下潜 | 与推进速度、船舵完全独立 |
| B | 应急上浮开关 | 严重受损时继续自动触发救援 |
| Q/E、方向键左右 | 额外镜头水平环视 | 不改变船舵 |
| 滚轮 | 拉近 / 拉远 | 镜头跟随目标具有时间阻尼 |
| V / X | 舰桥 / 外部视角；镜头正后方回中 | 不需要反复与镜头自动回正争抢 |
| H | 标准船舵 / 即时推进两模式切换 | 即时推进模式是按住 W/S 才移动，但两种模式的鼠标都只管镜头 |
| F、C、G、T、Z、R | 锁定、鱼雷、鱼叉、深弹、防御、声呐 | 原 V29.1 战斗输入保留 |

`Esc` 在鼠标被锁住时先释放鼠标，便于点击右上角的油门按钮；再次按 `Esc` 返回海面。游戏右上角同时显示「目标航速」「实际航速」「车钟档位」「方向舵角」，**它们是四个不同的数值**。

## 船舶交互的具体设计

- **持续车钟**：每次 W/S 按下，目标油门改变 25%。连续按住超过 0.20 秒后继续按每秒约 115% 的速率变化，最大范围为倒车 100% 到前进 100%。
- **车钟与真实物理独立**：车钟设置期望航速，实际速度仍受 78m/s² 加速和 112m/s² 制动限制。即使按键不再按住，目标速度也不会自动回零。
- **自动回中船舵**：A/D 改变渐变的舵角；释放后舵角快速趋近 0，船体角速度亦逐渐减小；倒车时保持合理的反向转舵关系。低速时舵效减弱，防止静止时像人物一样原地高速打转，同时保留有限的低速侧向推进效应。
- **完全隔离相机**：鼠标输入只能改变镜头目标水平/俯仰角，通过无帧率依赖的阻尼跟随到目标。船只转向的输入从 `KeyA/KeyD` 获取，绝不从 `movementX` 获取。鼠标手动观察可以取消 F 追踪，不会影响其他已发射鱼雷的制导状态。
- **两种模式均可使用**：默认标准船舵，H 切到即时推进（旧习惯 W 按住开、松开刹车），但不会恢复令人混淆的鼠标转船头机制。操作模式与镜头灵敏度保存到单独 V30 浏览器设置项，避免 V29 旧设置继续生效。

## 参考项目及许可边界

此次设计参考以下开源项目公开描述的驾驶行为，没有直接复制项目内部实现或捆绑它们的模型/声音文件：

1. Open Water（Three.js / MIT）：https://github.com/bob6664569/open-water — 持续油门杆、自动回正船舵、多相机视角的交互思想。
2. Submarine Simulation System（Three.js / MIT）：https://github.com/Abdalrahman-Alhamod/Submarine-Simulation-System — 独立方向舵、推进、升降舵/压载设计。
3. Camera Controls（Three.js / MIT）：https://github.com/yomotsu/camera-controls — 平滑镜头目标过渡理念。现有工程使用自研 WebGPU 引擎，没有直接添加 Three.js 相机库依赖。

## 验证

- `node test/stormwake-v30.mjs`：针对持久油门、逐档操作、回中船舵、镜头完全隔离、倒车、停止、HUD、30/60/144Hz 进行无 GPU 逻辑测试。
- `npm run test:v30`：新旧 V11–V30 连续回归，包含利维坦骨骼、战斗、伤害判定、岛屿生活与武器。
- `npm run build`：正式前端打包。
- 本执行环境无法提供 WebGPU 显卡进行真人手感测试，最终方向、俯仰和镜头舒适度仍需在你的电脑中试驾。

## 建议试驾流程

1. 进入深渊，不按任何键，旋转鼠标：船头必须不动，镜头旋转。
2. 短按 W 一次并松开：车钟显示前进 25%，潜艇继续向目标速度加速。
3. 再按住 W 一秒：车钟快速到 100%，松手不会停车；按住 Shift 可急速。
4. 航行时按 D：船向屏幕右侧转。松开 D：方向舵回中，船体逐渐保持直线。
5. 按 N：车钟归零，实际航速逐步降低；再按 S：车钟进倒车档。
6. Space/Ctrl 垂直航行并发射鱼雷 C、切换镜头 V；确认所有功能互不打架。
