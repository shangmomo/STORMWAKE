## 2. 远洋地理（世界坐标：m）

- 港口中心：`x=69.8,z=36.5`，范围内无风暴和龙卷吸力。
- 风暴走廊：`x=-800,z=2250`，雨、风、乌云。
- 幽灵舰队：`x=-600,z=2450`，10 艘会战船，位置与风暴区部分重叠。
- 水龙卷核心：`x≈-500,z≈3570`，可随时间缓慢漂移，吸力半径 560m。
- 东部蓝海：`x=970,z=1200`，中等海况。

玩家打开船长航海图 `Z`，选择区域 5、6、7，随地图指引出海。这些不是在近港生成的视觉假点；地形数据在该海域海底约 -90m。因为距离远，低速从港口航行需要一定时间。

## 3. 如何运行

1. Windows 解压 ZIP 到一个可写文件夹，关闭此前占用端口 5173 的 V43 服务。
2. 双击 `START_STORMWAKE_V44_P1.cmd`，或者打开终端执行 `python start_v44.py`；不需先安装 Vite。
3. 在支持 WebGPU 的新版 Edge/Chrome 中打开 `http://127.0.0.1:5173/?stormwake=1`。使用 `Z` 打开航海图，选择 5 风暴、6 幽灵舰队或 7 龙卷海域。
4. 单人：E 登船/操作岗位，舵 A/D 转向、W/S 辅机，帆索 W/S 收放、A/D 角度，船首锚 E 收放、R 还给 AI；离岗 Esc，海图 Z；原有 V43 舱口 E 上下舱，宝箱 E 抱起/取回，G 放下，舱内靠近货架按 E 存入。
5. 避免同时启动多个占用同端口的版本。GPU 浏览器内真实画面尚需本地验证。

- V43 15 项核心船舶与人物检查通过；V42、V41、V40、V39 与更旧回归链亦通过。
- Python 本地服务 `HTTP GET/HEAD /` 和 `/src/offshore/GhostFleet.js` 返回 200。
- Playwright Chromium 自动访问 localhost 被当前执行环境策略拒绝 `net::ERR_BLOCKED_BY_ADMINISTRATOR`，**故未能实际执行 Windows Edge/Chrome WebGPU 帧渲染与鼠标操控测试**。
- 上述测试证明源码中逻辑一致和静态服务可用，但不证明 GPU 着色器可成功编译、外观达到 3A，或全部真实交互均无 BUG。
