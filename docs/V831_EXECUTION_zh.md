# V83.1 — 沉岩洞、岸线及角色安全专项

## 实际实现
- 以带岩层、裂隙及苔藓变化的程序化岩面替换平滑外壳，移除旧后墙长方体碰撞代理；可见岩石网格与碰撞网格共享三角形。
- 调整通往化石谷的道路，绕开洞穴尾部；保留矿区后缘坡面与原有储水池、升降机功能。
- 储水面依据地形高度裁切，局部水体判断加入真实地面高度；材质增加波纹法线和岸边颜色变化。
- F 自由视角与角色分离。单人仅在干燥、支撑、胶囊净空和视线验证通过的近地镜头位置落地，否则回到原角色位置。联机退出自由视角不传送角色；禁止在升降机、战斗、岗位等不安全状态开启普通自由视角。
- 浏览器标题、启动器和版本说明统一 V83.1；保留现有 00_START_V83.cmd 入口。
