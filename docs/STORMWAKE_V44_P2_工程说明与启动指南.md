# STORMWAKE V44 P2 · 工程说明与启动指南

本 ZIP 是从 V43 完整工程及 V44 P1 继承的完整源码，不是单独的补丁。内含已有多年以来的游戏素材、WebGPU/WGSL 引擎和 `src`、`public`、`test`、`server`、`docs` 等目录。

## Windows 运行

1. 解压完整 ZIP，进入 `Tidewater_V44` 目录。
2. 双击 `START_STORMWAKE_V44_P2.cmd`，或者在命令行输入 `python start_v44.py`。
3. 浏览器使用 Chrome 或 Edge，访问：
   - 原 V44 船：`http://127.0.0.1:5173/?stormwake=1`
   - 新 23m 船工程预览：`http://127.0.0.1:5173/?stormwake=1&heritageShip=1`
4. P2 工程预览从港外深水 `(92,120)` 开始，玩家直接在船上，防止大船被挤进旧码头。不是最终开局布局。

## 你可以检查哪些实际改进

- `heritageShip=1`：长约 23.37m、宽约 5.9m 的大船工程预览，浮力/质量/碰撞/站位同步放大；旧船作为稳定模式保留。
- E 操作舱口后是连续约 1.05 秒的梯子过渡，而不是立即切到另一个楼层。
- 舱底箱子可根据空间寻位，箱体间保持最小距离，舱口不得被箱子堵住；可从真实位置取回。
- 大船前部和后部受到炮弹时使用完整尺寸的扫掠碰撞，不再只有小船中心能被命中。
- 继承 V44 P1 外围海域风暴/水龙卷吸力/10 艘幽灵船等原型逻辑。
- 航海图上的外海风暴与幽灵舰队有数公里距离，不都放在近海。

## 测试

在有 Node.js 的项目目录执行 `npm run test:v44`。本轮整条回归链返回 0，包含 V44 P2 11 项测试、30 秒静水模拟、V44 P1/旧版跨模块测试。详细日志在 `docs/STORMWAKE_V44_P2_最终自动化测试日志.txt`。回归不等于画面真实游玩测试。
