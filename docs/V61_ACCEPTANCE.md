## 已执行的验证

- `test/stormwake-v61-reliability.mjs` 覆盖连续碰撞、门扫掠、爬梯返回、交互选择、请求超时与拒绝、输入停用、绞盘协作、站位旋转、服务器可达性、倾斜坐标转换及姿态接管。
- V60→V58→V54 等既有逻辑、船舶、货物与真实 WebSocket 回归继续执行。历史测试保留；新版绞盘曲线仅对当前荷兰船启用，旧船与旧存档仍兼容。
- 扩展 `npm test` 包括实际 Dawn/WebGPU 引擎 smoke 测试。修复了旧测试默认写 `/tmp` 在 Windows 下失败的问题。
- 生产构建使用 Vite；日志保留现有的模块拆包提示，不将其当成画质或帧率证明。
- Windows Edge：货舱与船长室分别连续 20 次真实 E 往返；循环内部未使用 QA 传送。起点布景使用 `qa.go`，因此这些测试不能证明从出生点步行到码头的整条路线。
- 两个独立 WebGPU 页面：真实按键移动、对端可见位置更新、世界时间/天气以及锚机/舵轮操作。保留实际测得偏差，不将两端短测当作四人长测。
- 四个独立 WebGPU 页面已实际进入同一房间，分别占用 anchor / anchor_2 / anchor_3 / anchor_4，并观测到四人输入驱动同一锚链；房主离开后的剩余房主数量为一，已测切换船位变化约 0.027m。此为短测，不是 45 分钟连续任务验收。
- 首次最终轮曾因货舱行走测试朝向继承前一场景而失败：W 正对梯体，只移动约 0.089m。修正 QA 起始朝向后，真实 W 在空闲货舱通道移动约 0.439m，未降低测试距离门槛；旧失败报告保留。

最新报告与结果由随包的结构化清单索引。旧报告反映当时构建，新增改动后的最终验证另列，不能把历史截图当作最新版本截图。
