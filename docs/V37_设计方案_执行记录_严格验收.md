# Tidewater STORMWAKE V37 — 陆地升级设计、实施记录与严格验收

> 日期：2026-11-12。基线：V36 完整工程。状态：**程序验收通过；视觉与品质终验未完成**。本档包含已实施项与后续明确受阻项，不把自动化通过等同于 AAA 视觉品质。

## 1. 问题、事实、目标

用户从游戏画面确认：NPC 人物漂浮、行走不贴地、部分指令无效或冲突；海岛尺度大却缺少有层次的陆地冒险，要求风格化海盗人物和灵活陆地 Boss。优先级按 P0 接地 / 输入，P1 身份美术 / 导航，P1 Boss / 大岛地标，P2 完整美术重建与联网技术准备。

| 既有问题 | 源码根因 | 本版措施 | 验收边界 |
|---|---|---|---|
| 村民漂浮 | 之前将部分已足底对齐的 GLB 重复抬高约 1m；按骨架原点而非脚底定位 | `LandGrounding.js` 计算蒙皮后足底采样，动态抵消根节点偏移；`LandResidents.js` 移除额外固定 1m 抬升；导航读取同一平台/地形高度 | 已测试关节矩阵；无 WebGPU 实景逐帧落地验收 |
| 指令失效 | 船坞、海图、相机、任务、战斗多处分别读相同边沿键 | 输入消费/上下文优先级；在近岸 E 优先给陆地交互；手持武器不允许 Shift+J 打开船坞 | 自动化覆盖主要冲突；所有菜单组合键尚无穷举测试 |
| 村民美术相似 | 20 人共用少数现有角色网格 | 为主角、居民、Boss 添加原创三角帽、头巾、宽檐帽、航海软帽和腰带，沿头部/骨盆骨骼跟随 | 仅为第一轮造型区分，不是高精度全身海盗建模 |
| 大岛玩法稀疏 | 主要任务只有港口至灯塔通路 | 4 处新区域路牌和解说、荒潮营地精英支线及地形贴合战斗场地 | 导航路牌可互动，区域生态内容尚待完善 |
| 陆战 Boss 单一 | 旧 NPC 只会直线追逐和原地攻击 | `LandCorsairBrain.js` 独立状态机：绕侧、虚招、前刺、旋斩、招式预警、收招弱点、42% HP 转二阶段 | 30/60/144 FPS 状态机通过；专属动捕/实机打击感尚未验收 |

## 2. 研究、风格来源及授权

设计研究参考《Sea of Thieves》**夸张轮廓、粗实用布料、海风侵蚀金属、道具区分职业、英雄与居民差异**等美术语言。**不使用其版权角色、模型、贴图、音频或图标。** 所有当前新增服饰为本项目通过 GeoKit 程序生成的原始几何体。

对外部免费候选，已检索权利人与官方网站；**当前网络环境无法取得作者原始资产 ZIP，因此以下新素材没有被假装“实装”。**

- Quaternius Pirate Kit：https://quaternius.com/packs/piratekit.html （CC0，面向风格化海盗模型与场景组件）。候选，并未安装。
- Kenney Pirate Kit：https://kenney.nl/assets/pirate-kit （CC0，适用于道具与外观概念）。候选，并未安装。
- Quaternius Universal Animation Library：https://quaternius.com/packs/universalanimationlibrary.html （CC0，免费 Standard 与额外内容区分）。候选，并未安装。
- Khronos 的足部放置 IK 示例：https://github.khronos.org/Vulkan-Site/tutorial/latest/Advanced_glTF/Procedural_Animation_IK/04_foot_placement.html （用于接地算法设计参考）。

选材准入：核查原作者页面、许可证、允许再分发条款、完整动画和 GLB 文件、模型原点、贴图来源、三角面数与骨骼；不明来源不装包。

## 3. 实施方案与架构

### 3.1 接地与动作

1. 用 `parseGLB` + `SkinnedModel` 在本地求模型的关节矩阵，选取低位顶点，计算骨骼变形后足底 `soleY(t)`，替代硬编码 +1m。
2. `LandFootPlant` 运行时矫正 GLB 局部根位移，`LandVillageNavigator.groundAt` 同时读取地形高度与可行走平台高度，`followGround` 用指数平滑避免小坡度弹跳。
3. NPC 仍使用现有合法骨骼与动作资源；行走、奔跑、受击等动作保留 V36 的动作映射，不复制《盗贼之海》动作。
4. **限制**：尚未实现逐脚双脚 IK、坡面脚踝旋转、动作驱动的 root motion 与服饰布料物理；复杂斜坡可能残留滑步或穿插。

### 3.2 输入上下文

| 场景 | 按键 | 拥有者 | 冲突防护 |
|---|---|---|---|
| 陆地探索 | W/A/S/D | 玩家移动 | 不改变潜艇车钟绑定 |
| 陆地探索 | E | 最近且优先级最高的机关、居民、任务路牌 | 在 `Player.update` 之前，附近地标预认领 E |
| 陆地探索 | Z | 拔刀/收刀 | 不再同时弹海图 |
| 陆地战斗 | J/鼠标左键 | 轻击 | `Shift+J` 不会攻击 |
| 陆地战斗 | K | 重击 | 持刀时禁止全局小汐 K 面板抢键 |
| 陆地战斗 | Q/鼠标右键 | 闪避/格挡 | 不影响登船时操作 |
| 所有步行状态 | P | 任务日志 | Shift+P 单独交给拍照 |
| 港口且未拔刀 | Shift+J | 船坞换船 | 持刀时不允许打开船坞 |
| 陆地 | Shift+K | 小汐面板 | 分离重击及 NPC 面板 |
| 船舶/潜艇 | W/S、A/D、鼠标 | 车钟、舵、观察 | 维持 V30 船舶控制与既有海战快捷键 |

### 3.3 大岛分区与视觉导航

| 地区 | 大致世界坐标 (x,z) | 功能与交互 |
|---|---|---|
| 海风古道 | (20,-132) | 港口—密林入口，旧路标与航路提示 |
| 灰苔密林 | (-56,-174) | 隐蔽森林、足迹、潮蚀石头、与旧主线连接 |
| 荒潮营地 | (-101,-185) | 约半径 22m 的 Boss 支线战区，木架、漂流物、篝火残骸，路牌介绍 |
| 被淹没的石道 | (-82,-208) | 指向断崖灯塔的旧祭坛通路，连续探索目标 |

为避免悬浮营地，`LandCorsairArena.js` 以每个建筑部件的世界 x/z 查询地形高度并设置相对落点，合并生成单 mesh 降低绘制成本。此处是地形适配和导览增加，不是重做整岛的植被、地貌及生态系统。

### 3.4 BOSS「荒潮掠影 · 凯洛」

位置 (-101,-185)，HP 720，行动限制约 25m，探索任务第一阶段后激活。底层状态及攻击权威可用于今后联机验证。具体设计：

- `circle`：横向绕侧 1.85m/s，低血量 2.65m/s，按攻击次数决定换向；避免永远正面直扑。
- `telegraph`：快斩 0.72s；前刺 0.87s；旋斩 1.10s；虚招 0.54s，第二阶段蓄力缩短至 82%。
- `lunge`：前刺以有限速度 9.0m/s 冲 0.34s；第二阶段 11.5m/s。**不是位置跳变**。
- `recover`：有明显恢复停顿，玩家在恢复阶段攻击有 1.35 倍伤害。
- `stagger`：受到伤害进入 0.28s 硬直；`dead`：记录独立任务进度与一次性奖励。
- HP 低于 42% 开始二阶段，改变攻击顺序和运动速度。
- 实际攻击必须再过：时序编号、有效范围、垂直高度、障碍阻挡、玩家翻滚/格挡/无敌帧，伤害只由游戏层判定。

**仍未完成**：全身独有海盗 Boss 美术、动作捕捉级攻击动画、Boss 独有音效、地面受击痕迹、战斗镜头震动精调，均不能以“状态机通过”替代。

### 3.5 为以后联机准备

玩家行为事件保留 `(actorId, sequence, tick, action, direction)` 规范；交互意图保留 `(verb,targetId)`，并在前端声明 `damage:null`、`reward:null`，实际未来服务器须重新验证距离、动作时间、攻击目标和奖励。Boss 状态更新不依赖浏览器 DOM，易移植至服务端，但**V37 没有上线真正的多人同步或服务端权威战斗**。

## 5. 后续正式美术准入的逐项检查清单

每一位角色要求：(1) 来源和授权可再分发；(2) 网格、贴图、可见轮廓；(3) 骨骼数、单位比例、负权重检查；(4) 含 idle/walk/run/turn/hit/death 的**实际**动作；(5) 脚尖/脚跟在台阶、石台和连续坡面不少于 30 秒回归；(6) 人数高峰压力下的 GPU draw calls、显存和帧率；(7) 离线安装/恢复；(8) 临近 NPC 对话与按键互斥，(9) 被击中时接触帧与碰撞体一致。

Boss 再加：后背/侧面/正面攻击、相机环绕、入场退场、玩家不同速度时招式预兆及公平反应时间、死角边界保护、伤害单次结算、重复加载不刷奖励、联机输入延迟模拟。

## 6. 启动与检测

- Windows：`python start_v37.py`，启动器会检测/安装依赖并启动本地 WebGPU 开发页。
- 已有 Node.js 依赖时：`npm run test:v37`。
- 生产构建须先执行 `npm ci`，然后 `npm run build`。
- 冷启动/离线资源加载、画面和操控最终仍需要具备浏览器 GPU 能力的环境检查。

最后提醒：V37 是可恢复、可审计的代码升级基础版；若实际目标是“完整《盗贼之海》风格重塑 + 3A 级 Boss”，后续必须投入专门的模型/动画美术资产及逐帧实机 QA。**禁止用程序合格代替视觉合格。**
