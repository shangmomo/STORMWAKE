### 如何将你下载的作者模型替换进本工程

1. 在上方原版 Sketchfab 页面登录你自己的账户，点击 **Download 3D Model**，优先选择 glTF 2.0 格式；下载后保留许可证和作者信息，并将模型 ZIP 发给开发对话，便于检查网格、PBR 贴图、骨骼、纹理引用。
2. 如果文件只有静态 FBX/OBJ/glTF，则**先在 Blender 绑定真实的脊椎、头颌、双鳍、尾鳍骨骼并制作循环游动/蓄力/冲撞 Action**。不能直接用材质顶点拉伸冒充骨骼动画。
3. Blender 导出带有网格 Skin 和 Animation clips 的、纹理已打包的单一 `.glb`，放到：

   `public/models/titans/external/leviathan-monster.glb`

4. 进入游戏时会优先尝试加载并播放外部模型的动画。未找到则自动加载 `public/models/titans/rigged/sea-god-skeleton.glb`。Boss 的碰撞长度暂以旧关卡为准；真正换模后应重新校准头颌碰撞舱、体长、伤害窗口与各段动画事件。

**重要**：本次已完成潜艇摄像机和灯光代码，但由于官方登录限制，未获取上述美术模型，不能称“外观替换完成”。没有进行真实 GPU 画面验收，因此也不能承诺每种显卡都无卡顿。

## 运行与验证

Windows 原项目保持不变：运行 `python run_windows.py`，开发模式可直接进入潜航场景；也保留原有工坊解锁。

自动化：`npm run test:v24`。V24 新增针对环视数学、潜望镜几何、三光源灯位、光锥向量、键位冲突和可选模型源的断言，同时级联 V23→V11 既有测试。它**不是实际浏览器/WebGPU 帧率测试**。

当前执行环境未安装 `vite`，`npm run build` 返回 `vite: not found`；Windows 若首次启动需要按项目指引安装 npm 依赖。V24 尚需在你本机观察水下体积光照、曝光与帧率，并根据真实屏幕结果微调灯的半锥角、发光功率、相机间距。
