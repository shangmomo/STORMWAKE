# STORMWAKE V80 实施验收报告

定位：V79总体设计的完整工程阶段交付，不是通过所有发布门槛的最终成品。

## 已实施

- 深海魔鲸号：首、中、尾三个各500耐久分舱，按命中位置受损，过量伤害转移；独立积水、空气、排水泵、隔舱水交换。动力、转向、压载和姿态受积水与电力影响，低氧触发应急上浮。真实攻击调用分舱逻辑，水柱攻击检查纵向艇体。隔舱门和积水具有可见几何，关闭双向阻挡通行，拒绝夹住玩家。工程岗J排水、Y启动2.5秒维修，离岗中断不扣材料，完成消耗1份零件恢复最多180耐久，冷却8秒。HUD、联机快照与服务器权限和位置校验已接入。房主仍承担主要模拟。
- 沉岩洞：同层洞尾扩展约23米，新增岩顶、支撑、矿轨、采掘台及独立储水池（水深约2.8米）。西侧干路、东侧游泳及上岸；击败荒潮船长并调查原岩心后可登记矿样，首次奖励120金币。存储异常后自动补发，回执防重。初测曾影响化石谷坡度，调整地形融合范围后旧路线回归通过。
- 更新启动入口00_START_V80.cmd及start_v80.py；原始public资产与V79递归比较无差异。

## 自主决策与未完成门槛

- 保留自研WebGPU/WGSL及原有美术，未迁移官方Three.js/TSL。
- 分舱水氧电是近似玩法模拟，不是流体工程仿真；修理仍通过岗位，不是逐个实体破口修复。外部真实舱口、完整压力互锁、独立服务器权威仍待施工。部分范围伤害仍按中央命中处理，未实测平衡性。
- 地下扩展不是多层地下城；升降机、大型地下湖、Lurker和局部水下后处理仍未完成。
- 酒馆全楼层、帆船索具和船体碰撞、完整任务图、巨兽骨骼动作、人物衣物与手脚接触及全场景视觉验收仍有积压。未证明无穿模或无卡死。
- 四人两小时压力测试、无夹具通关、逐场景GPU帧时和第三方资产授权尚未完成；公开发行前须复核授权。
