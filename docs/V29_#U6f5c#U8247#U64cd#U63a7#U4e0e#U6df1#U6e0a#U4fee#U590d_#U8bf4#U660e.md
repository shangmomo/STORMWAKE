# Tidewater V29 · 深渊潜艇驾驶体验升级

这是以你提供的 V28 完整工程为基础的增量改进版，保留原有岛屿、港口、海洋、利维坦骨骼动画、模型、装备、进度与战斗机制。

## 直接启动

1. 将压缩包完整解压。电脑需要 Node.js 20+、Python 3 和支持 WebGPU 的 Chrome/Edge。
2. Windows 在工程目录运行 `python start_v29.py`；Linux/macOS 运行 `python3 start_v29.py`。
3. 启动器会安装缺失的依赖，并打开 `http://127.0.0.1:5206`。
4. 进入游戏，使用此前的游戏进度在军械锻造界面进入海神深渊。进度仍使用浏览器原有存储；若换浏览器、域名或端口，原有进度不会自动出现。

## 驾驶操作

| 操作 | 默认鼠标掌舵 | 传统船舵（按 H 切换） |
| --- | --- | --- |
| W / S | 前进 / 倒车 | 前进 / 倒车 |
| 鼠标左右 | **鼠标向右，船头在屏幕中向右转**；向左同理 | 鼠标向右，视角向右看；船头不动 |
| A / D | A 向屏幕左转，D 向屏幕右转 | A 向屏幕左转，D 向屏幕右转 |
| 按住鼠标右键 / Alt | 自由观察，不改变潜艇航向 | 自由观察 |
| Space / Ctrl | 独立上浮 / 下潜 | 独立上浮 / 下潜 |
| Shift | 急速推进 | 急速推进 |
| B | 手动开启 / 取消应急上浮 | 相同 |
| V / X | 第三人称与潜望镜切换 / 镜头回正 | 相同 |
| 滚轮 | 拉近 / 拉远镜头 | 相同 |
| H | 切换船舵控制模式 | 切换鼠标控制模式 |
| HUD 灵敏度按钮 | 低 / 中 / 高，自动保存 | 影响鼠标环视速度 |

**鼠标必须先点击游戏画面进入捕获状态**；也可按住鼠标左键拖动。`Esc` 第一次释放鼠标以操作 HUD，再按一次退出战斗。控制模式与鼠标灵敏度在当前浏览器本地保存。

## 重新调校的驾驶参数

- 巡航上限：72 → **86 m/s**；Shift 急速上限：88 → **116 m/s**；倒车：26 → **34 m/s**。
- 加速能力：46 → **78 m/s²**；制动：74 → **112 m/s²**。松开 W 后主动减速，不再长时间持续惯性滑行。
- A/D 船舵最大转向速度：0.80 → **1.02 rad/s**；鼠标掌舵有单独上限 **1.58 rad/s**，兼顾响应与惯性。
- 垂直升沉上限：26 → **36 m/s**；无前进动力时也可上浮和下潜。
- 鼠标输入产生目标航向，实际转向有限速和平滑过渡；与不同屏幕刷新率无关，转向接近 ±180° 时不会发生突跳。
- 第三人称初始距离 46m，修复潜望镜和第三人称中向下看却抬头的俯仰方向错误；鼠标掌舵模式镜头回到潜艇后方，传统船舵模式不再自动与鼠标争夺镜头方向。
- **V29.1 纠偏**：按真实追尾镜头的屏幕方向重新统一鼠标掌舵、右键自由观察、A/D 船舵、Q/E 环视以及声呐「左转/右转」提示，修复世界坐标正负号反用造成的反向操作。

## 战斗及系统修复

1. **锁定追踪鱼雷**：`F` 锁定后发射的鱼雷保留制导状态，即使随后切换镜头或解除锁定，也能持续修正飞行轨迹；仍需实际三维碰撞才能造成伤害。
2. **潜艇速度与航向仪表**：右上角显示每帧实际更新的速度（m/s，一位小数）、动态图形速度条、推进/制动状态、航向和操控模式。深渊时彻底隐藏旧海面船舶「knots」圆表；它显示的是另一个船的速度，曾在深渊画面中错误覆盖。
3. **海面与深渊输入隔离**：`Z` 反声波不会误开海图；`X` 镜头回正不会误触海面船只脱困；`H` 切换驾驶模式不会打开海面设置面板。深渊期间暂停海面船只物理、拖网捕鱼与钓鱼/柴油消耗逻辑。
4. **完整退出清理**：离开深渊时清理未命中的鱼雷和爆炸粒子，并释放鼠标捕获，避免海面留下冻结的弹体。
5. **海域边界不再卡死**：旧版到达半径 640 米的边界时直接清零水平速度，因此截图中显示 0/116m/s，W 也无法脱困。V29.1 扩大核心巡逻提示范围至 1800 米，并让边界只负责导航提示，不再强制停止移动，避免潜艇被困在危险水压区。
6. **最大深度与安全上浮**：到达 390 米上限时，升沉速度也正确归零，不再显示虚假的 -20 m/s。当潜艇船体严重受损、仍在高水压区时，自动启动紧急上浮；也可按 B 手动启动。海面时钟、岛屿伙伴和海面船表不再覆盖深海战斗 HUD。

## 验证

- `npm run test:v29`：包括 V29.1 操作方向、穿越原有海域边界后持续加速、实时航速变化、最大深度阻挡、受损自动上浮，以及 V28~V11 回归测试。
- `npm run build`：正式前端打包检测。
- 如需手动检查潜艇手感：重点测试「鼠标向右 → 船头向右；D → 向右；W → 右上角速度增加；Shift → 超过巡航上限；右键向右 → 只看右侧；Ctrl 深潜到 390m → 下沉读数归零；B → 上浮；Esc → 返回海面」。

## 诚实的完成边界

此次改善主要针对**操作手感、输入冲突、镜头、追踪武器、界面和退出状态**。利维坦原有 136 骨骼与动画仍保留，但未重做全新的商业 AAA 级资产或物理流体引擎；具体手感还需要你在自己的电脑上试驾后按个人偏好再精调。
