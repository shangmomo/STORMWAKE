# Stormwake V27 — 利维坦战斗、真实咬合与镜头控制

## 交付改动

1. **修复 V26 主岛黑屏**：`src/ocean/UnderwaterLighting.js` 原 WGSL 用 `let atten` 声明不可变局部变量，随后又赋值。改为 `var atten`，防止 WGSL 编译失败导致全局材质渲染失效。
2. **镜头操控隔离**：潜艇战斗采用鼠标**右键按住拖动**环视；鼠标左键和普通点击不会在战斗中重新捕获指针。潜艇方向仅由 A/D 控制，与观察方向解耦。鼠标向右拖动，镜头朝右旋转。离开深海后恢复主游戏原来的输入模式。
3. **F 目标锁定**：按 F 平滑将镜头朝向海神；再次按 F 或手动拖动鼠标即可退出锁定。V 切换第三人称/潜望镜，X 解除锁定并回正，滚轮改变距离。F 不会切换调试自由摄像机。
4. **更活跃的海神 AI**：海神的出场深度调整，使玩家能看到它的靠近。巡游最高约 21–27 m/s，冲刺阶段随阶段升至 43–53 m/s；速度由限加速度函数变化，而非瞬间跳变。偏航/俯仰均受限，移动方向与可见身体朝向统一，转身不再横向滑行。
5. **嘴部可见张合**：对原模型进行了结构检查——艺术版利维坦确有 66 个蒙皮关节与 Swim / Charge / Attack 动画，但**没有单独下颚关节**。V27 在其实际头部局部顶点上加入受 `biteOpen` 控制的局部下颚形变，蓄力张嘴，命中时收口，保持其他身体网格与原始动画。没有伪称艺术师制作了不存在的下颚动作。
6. **真正接触才受伤**：鼻尖参考点位于可见怪物前端，前后两帧的位置构成扫掠线段；玩家潜艇用沿船身的 3D 胶囊表示。只有两个空间体相交才触发单次咬击、`bite` 状态、下颚收口、伤害、爆发粒子和击退。远距离、不同深度、擦肩而过都不会凭中心距离直接扣血；冲锋可以躲闪。
7. **战斗反馈**：命中时音效、船体受冲击的惯性滑移、镜头震动、HUD 短暂受击边缘提示。鱼雷命中则触发怪物伤口色脉冲。
8. 保留 V25/V26 的 SDC Nautilus 与 Lebin Benny Leviathan 真实模型、返回主岛传送、探照灯与原海岛存档、船舶经济及全部早期 Boss 系统。

## 操控一览

| 控制 | 功能 |
|---|---|
| W / S | 推进/倒车 |
| A / D | 潜艇左/右转向 |
| Space / Ctrl | 上浮/下潜 |
| 鼠标右键按住并拖动 | 自由观察（不改变潜艇航向） |
| Q / E | 键盘环视 |
| F | 锁定/解除锁定利维坦；手动环视自动解除 |
| 滚轮 | 镜头拉近/拉远 |
| V / X | 切换镜头/回正 |
| C / R / L | 鱼雷/主动声呐/探照灯 |
| HUD 右上角按钮 | 回到海面 / 传送回主岛 |

## 验证情况与边界

- V27 逻辑测试覆盖鼠标控制隔离、WGSL 声明错误、3D 胶囊-扫掠接触、扑空不扣血、实际咬击一次、速度连续性和艺术网格下颚形变。
- V26→V11 的完整自动化回归运行通过。
- Blender 对上传的 Leviathan GLB 做了离线渲染并检查局部下颚开合区域。游戏仍使用原 GLB，运行时代码叠加变形，没有破坏原作者模型文件。
- 本环境未能实际运行浏览器 WebGPU 渲染管线；正式验收需在用户本机运行一局，确认屏幕呈现、张嘴、声像、操控手感和硬件帧率。此版本是针对具体问题的可测迭代，**不冒称已经达到商业 3A 动作捕捉或物理品质**。

### Windows 运行

将完整压缩包解压到独立目录，双击/运行 `python run_windows.py`，在显示的本地页面进入游戏。**请不要把旧版缺少的模型目录混合覆盖到新版**；本包已包含两个真实模型及其依赖。
