# Stormwake V28 · 深海魔鲸号 / 利维坦大幅升级

## 驾驶重构（与主岛舵轮逻辑统一）

- 点击游戏画面：浏览器 Pointer Lock 捕获鼠标，鼠标直接控制镜头环视。按 Esc 首次释放鼠标，用鼠标点按 HUD；再次 Esc 可离开深海战场。也保留左右键按住拖动的临时自由视角。
- `W/S` 油门前进／倒车；`A/D` 操纵潜艇舵机（独立于鼠标视角），取消 V27 缓慢而不直观的长时间偏航缓动。
- `Shift` 冲刺，最高 **88 m/s**；常规最高 **72 m/s**。利维坦最大冲刺 **60 m/s**，因而有真正的逃脱空间。倒车与减速不再使用同一惯性参数。
- `Space` 独立上浮，`Ctrl` 独立下潜，最大升沉约 26 m/s；视觉艏倾由升沉速率驱动，与航向／发射方向分离。
- `V` 舰桥／第三人称切换；`X` 镜头回正；`F` 临时锁定利维坦；滚轮缩放。镜头在无人操控时缓慢回归舰尾方向。
- 保留返回海面和**传送回主岛**功能。深渊退出后仍然恢复主岛船只与角色控制。

## 70 根新增真实蒙皮骨骼

载入用户提供的 66 骨骼、3 原始动画 `Swim`、`Charge`、`Attack` 的 Lebin Leviathan GLB；在解码后原位加装关节（不覆盖原动画）：

| 身体结构 | 新增骨骼 | 动作驱动 |
| --- | ---: | --- |
| 左右胸鳍 | 24 | 左右非完全对称的升降、转向调整 |
| 左右尾鳍 | 20 | 与速度、冲刺状态相关的推进波相位 |
| 背鳍 | 10 | 次级水动力摆动 |
| 下颌 | 8 | 张口咬合及蓄力开口，与嘴部形变叠加 |
| 左右鳃部 | 8 | 缓慢呼吸式起伏 |
| **新增合计** | **70** | **总骨骼 136** |

新骨骼不是空名字：每根骨骼都有自己 glTF 节点、逆绑定矩阵、蒙皮权重；对当前随包授权模型检查，有 **8,465 个网格顶点** 受到新增关节影响，所有权重归一。使用程序化次级动作叠加作者动画，帧率变化不会改变波形连续性。

## 利维坦战斗（五种不同战术）

1. **高压水炮**：张口蓄力，连续发射可见的蓝色高压弹体，带水泡粒子轨迹；弹体使用三维扫掠检测与潜艇船体发生真实接触才能造成伤害。
2. **方向性超低频声波**：脊骨蓄力后发出三维锥形声压波；锥外及身后不会受伤，前进的可见声波环对应传播距离，可被反相脉冲抵消。
3. **张颚冲撞**：延续 V27 的真实三维口部扫掠与船体胶囊接触；擦边和未接触不会凭空扣血。
4. **全向压力波**：范围传播冲击，需要掌握距离和水深。
5. **深渊涡流**：一定范围内牵引潜艇，近距离压力撞击。

三个血量阶段逐渐组合上述招式。利维坦追击速度提升，但冲刺仍比潜艇慢，保证有策略性的回避、转向与反击。

## 启动 / 验证

- Windows/Linux/macOS：在项目目录运行 `python start_v28.py`，访问 `http://localhost:5206`。
- 手工方式：`npm ci`，然后 `npm run dev -- --port 5206`。
- 正式构建：`npm run build`。
- 游戏逻辑/骨骼/战斗及旧版回归：`npm run test:v28`。

## 完成边界

此版本进行了真实新增蒙皮权重与动作驱动、可测试的三维战斗逻辑，但**不能在没有浏览器实际观察与角色特写的情况下宣称达到了商业 3A 成片质量**。如需 AAA 级骨骼肌肉体积、下颌硬表面内侧牙床、流体碰撞网格、引擎音效与粒子风暴，还需在 Blender / Maya 资产工作流中进一步制作。新手感是否符合个人习惯也应由玩家上机测试。
