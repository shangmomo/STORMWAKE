# Tidewater / Stormwake V23：终章「海神利维坦」与「深海魔鲸号」

## 本版已实现

本版在 **V22 自研 WebGPU 引擎**工程上增量开发，不更换引擎，不重置已有船舶、4 种海怪、海水、岛屿、武器、联机接口或 V13 狩猎存档。原本名为 `leviathan` 的内部对象仍是「三首深海魇龙」；新海神使用独立的 `sea_god`，杜绝旧对象与新终章混淆。

### 新流程

1. 击败「三首深海魇龙」，额外掉落一颗「魇龙深渊心核」。
2. 进入 `G` 军械锻造台，使用心核×1、魇龙鳞×2、鱼骨×8、鱼油×8、沉船铁料×15、深渊墨囊×1，建造「深海魔鲸号」。
3. 点击军械台中的「进入深渊」，驾驶潜艇前往「无光王庭 · 海神之渊」，挑战新增海神。
4. 击败后获得「海神源质」战利品，记录独立的 `sea_god` 战绩，存入原狩猎存档。
5. 老版已击败魇龙的存档会被识别，未制造魔鲸号者补发一次心核，不要求重刷旧 Boss；战利品奖励采用去重凭据，避免重复刷取。

**开发者快捷体验**：游戏默认开发者模式开启（`?dev=0` 可切换正常进度限制）。在军械台直接点击「驾驶魔鲸号，进入深渊」，不必先收集材料；此前「带船传送到四只水面海怪」的功能继续保留。

### 水下驾驶键位

| 键位 | 功能 |
|---|---|
| `W` / `S` | 受惯性限制的前进 / 后退 |
| `A` / `D` | 转向（转向速度随航速变化） |
| `Space` / `Ctrl` | 上浮 / 下潜 |
| `C` | 发射声呐制导鱼雷；有装填间隔 |
| `R` | 主动声呐：短时间开启渐进追踪与距离测量 |
| `V` | 船外追逐镜头 / 艇桥视角切换 |
| `Esc` | 中途返回水面，保留原船与原船长位置 |

### 新海神三阶段

| 阶段 | HP | 行为 |
|---|---|---|
| I · 沉眠巡猎 | 100%–70% | 巨颚张开，缓转锁定，冲撞潜艇；命中须满足真实 3D 空间距离 |
| II · 深渊律动 | 70%–30% | 冲撞与扩张声压冲击交替；冲击波穿越艇体球壳范围时才结算伤害 |
| III · 海神暴怒 | 30%–0% | 深渊涡流将艇体拉向海神，再混合高伤冲撞与快速声压波 |

还实现了深度安全水压、越限损伤、三维鱼雷弹道及其缓慢转向、命中粒子、船体受击减速和镜头震动、终局提示与回航。

## 运行与验收

在本工程目录运行：

```text
npm install
npm run dev
```

浏览器需支持 WebGPU。完整 V11–V23 逻辑回归：

```text
npm run test:v23
```

仅 V23 骨骼与进度逻辑检查：

```text
node test/stormwake-v23.mjs
```

本轮已在 Linux 上执行 V23 独立用例、V22→V11 历史测试链、真实 GLB 反解析、实际蒙皮动画 160 帧矩阵有限性检查、Blender 生成与图片输出。**未完成浏览器真实 GPU 的游戏运行截图与 FPS 验收**：当前运行环境缺少 Vite 依赖缓存，离线安装 `webgpu@0.6.1` 失败。因此不能宣称已达稳定 60 FPS 或商业 3A 画质。

## 视觉质量与下一轮工作

目前的模型已脱离“单张贴图伸缩”，是真实可变形骨骼和建模实体；但仍属于原创可玩的第一版美术模型。它没有高分辨率雕刻烘焙法线、真实皮肤次表面散射、肌肉动力学、艺术家手工动画，也没有独立粒子体积水流系统；其视效尚不等于商业 3A 成品。终局战水下冲击波和涡流属于可交互的游戏物理近似，而非 Navier–Stokes 全流体模拟。水面 V22 海浪系统未被替换或重写。**终局战目前按单人本地战斗运行，未增加多人联机同步和水下地形障碍物碰撞。**

若下一步进一步打磨真实感，优先顺序：

1. **高模替换**：选择下载可授权的利维坦/潜艇高质量模型，匹配本版前向轴、世界尺度、骨骼命名和游戏碰撞区域。
2. **水下氛围**：海底峡谷、距离雾、局部体积散射、探照灯、悬浮颗粒和水压破裂泡群；近距离细节应有特定 LOD。
3. **动作打磨**：独立攻击时间轴、嘴内齿龈与咬合约束、鱼雷碰撞处受击混合形变、海神鳍/长须的二级惯性。
4. **实机调优**：目标设备 RTX 4060 Laptop 8GB 分别测试 1080p / 1440p，统计 GPU / CPU 帧耗，按压力预算优化骨骼更新和粒子上限。
