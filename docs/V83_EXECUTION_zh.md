# STORMWAKE V83 — 深层巢穴、压力舱口与联机接管

## 实际施工
- Lurker：西侧干燥巢穴 (337.2,-615.7)，380 HP。上层矿脉登记后解锁；单人限定。三种有方向/范围预警的攻击、半血变化、收招、脱战、死亡重试、首次 220 金币回执。复用既有武器、命中、格挡、闪避、阻挡射线。原创程序化分节模型，并非外购骨骼 GLB；未做 GPU 视觉/动作验收。
- 地下路标：沿经过碰撞测试的干路设置贴地蓝色箭头，绕开旧支柱。保留采掘台、水池、备用楼梯，未将原储水池冒称完整地下湖。原储水池容量与地形未扩大。
- 升降机：服务器确认请求距离、门口占用、竞争请求；350ms 二次复检。统一状态版本，移动过程中关闭所有门，到站后才开对应门。乘员随平台移动，客户端预测与版本校正；失去同步时旧楼梯保留。测试使用实际平台碰撞、客户端位置校正及四 WebSocket 客户端，不等同于四人实机乘坐。
- 魔鲸号：中舱开孔、真实梯位、1.52m 气密通道、封闭栏杆检修平台。两套原始模型在运行时切除实测开孔内三角形，原始资源不变。单人击败海神后在约12–20m浅水停船，中舱 HP≥410、积水≤12%、氧≥75%，离开岗位靠近中舱中央按 O。进入梯位→爬升→内门关闭→充水均压→外门打开→爬上平台→外门关闭。WASD 仅在检修平台范围内有效，O 返回，60秒外部停留预算耗尽自动返舱，双门永不同时开。该机制为受控路径与局部坐标限制，不是全艇自由潜水、角色骨骼攀爬或真实水力学；外部阶段停船并暂停潜艇战斗物理。退出整场潜艇实例仍可安全返回旧海面位置。两套 GLB CPU 开孔及 30/60/144Hz 状态机通过；视觉仍未验收。
- 潜艇房主迁移：原房主正常离开或连接关闭时，从3秒内最近一次服务器验证的完整快照接管；按剩余成员加入顺序选新主机。先广播清理后的快照，再发布主机变更。保留船体、舱室、弹药、零件、首领血量，取消未完成攻击和维修；没有完整新鲜快照时安全结束该局，不凭空重建。仍为房主模拟，不是全局服务器权威战斗。
- 保留既有 V82 防穿模、移动表面、持续操作互锁等修复。本轮新增 Lurker 碰撞启用后持续保持，避免近距离反复开关；气密舱期间禁止岗位、武器、门、推进等冲突操作。

## 使用
完整解压运行 00_START_V83.cmd。多人需要所有玩家及服务器都使用 V83。测试 Node.js 22+：npm run test:v83。
地下线路：先击败荒潮船长，完成深层岩心、采掘台、上层矿脉，然后沿蓝箭头进入西侧干燥巢穴。
魔鲸号：胜利后驾驶上浮至12–20m、N停车、离岗，WASD走到中舱正中央，O 出舱，平台中 O 返回。不能用于战斗期间、多人或损伤超限。
