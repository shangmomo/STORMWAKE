# STORMWAKE V38：海盗角色重构与陆地质量审查

## 本次实际写入、可离线复现的内容

1. **20 名村民、船长与荒潮掠影 Boss**：`public/models/land/v38_pirate_cast_manifest.json` 为 22 个岗位指定真实蒙皮 GLB 资源。使用已经存在于 V37 工作树中的 Quaternius Animated Man 与 RPG Character Pack 源文件，派生出 **12 个 GLB**：改变材质配色但保留原骨架、顶点权重、动画通道和二进制顶点数据。角色进一步加上游戏原作的三角帽/水手帽/头巾、厚外套/肩饰、扣带，Boss 的弯刀与右手骨骼运动一致。它们是风格化角色，**不是复制《盗贼之海》模型，也不能声称达到同等级美术质量**。
2. **接地**：`LandGrounding.js` 按蒙皮后的鞋底位置校准基准高度，取两脚在地形上的不同落脚高度并进行受限、时间步一致的微调。`LandResidents.js`、`LandAvatar.js` 使用真实地形探针。旧版约 1 米重复升高的风险被消除。当前属于鞋底高度校准，**非完整双足 IK**。
3. **按键互斥**：修复角色武器、拍照、任务、船坞和小汐面板的抢键优先级；打开菜单时释放上一场景尚被认为按住的键，不在菜单关闭后重放上一帧攻击。
4. **陆地 Boss**：继续使用 V37 的绕行、假动作、冲刺、旋斩、阶段变化、预告与收招破绽，改为 `pirate_corsair_boss.glb` 真正的蒙皮角色。攻击类型现在可触发不同动画片段，侧向运动连续。
5. **离线启动**：新增 `start_v38.py`，使用 Python 标准库启动本地 HTTP 服务器，兼容 Vite 项目里的 `public/` 资源根、`import.meta.env` 与样式模块的加载。*此项不代表已经通过可用 WebGPU 设备的最终画面验证。*

## 使用方法

解压一个完整 ZIP，进入 `Tidewater_V38` 文件夹，运行：

```powershell
python start_v38.py
```

浏览器建议使用支持 WebGPU 的最新版 Edge/Chrome。关闭命令行窗口即可结束本地服务器。

有 Node.js / npm 且**已安装依赖**时也可使用旧的 Vite 启动方式（`npm run dev`）。

重新制作 12 套 GLB 服装配色：

```powershell
python tools/build_v38_pirate_cast.py
```

工程内离线检测（Node.js 20+）：

```powershell
node test/stormwake-v38.mjs
python tools/test_start_v38.py
```

## 仍未通过、不应掩盖的要求

- 此执行环境无法完成带真实 WebGPU 适配器的画面和主观手感终验。游戏里某些陡坡、复杂台阶的脚步观感仍可能需要人工调节，当前不是完整脚掌 IK。
- 角色外观确有 12 套不同颜色以及不同服饰配件，但主网格仍来自两类基础角色，不是 20 个完全不同拓扑结构、专业建模的写实或商业 3A 角色。
- 外部 Kenney/Quaternius Pirate Kit 原始 ZIP 在当前网络条件下未取得，不宣称安装。
- 当前环境没有 npm 的 Vite/WebGPU 依赖，`npm run build`、`test:course` 的部分集成测试及原生 WebGPU 测试**没有成功执行**；不等于编译或画面实测已通过。
- Boss 动画是已有骨骼动作加独立 AI，没有全新专业动捕演出、物理布料、完整足部 IK 或联网端到端实战验收。联机保持旧版系统和事件接口，**新陆地 Boss 没有声称是成熟的服务器权威多人战斗**。

**质量结论**：V38 完成了可核查的源代码/模型升级、程序级回归与无 npm 启动；尚不足以宣称达到“完美 3A”或替代 Windows WebGPU 试玩验收。
