# STORMWAKE V43：实际源码变更、质量验收与未完成项

执行日期：2026-11-13。基线：用户上传的 `STORMWAKE_V42_FullSource_DeepGameplay.zip`（777 个文件）。

## 0. 严格结论

本轮已经**修改原有完整游戏代码**，接入船体局部破口、可从甲板舱口进入的低矮舱底、实际位置修补、有限弹药与木板库存、分阶段炮械状态机、沿甲板路网运动且能取板修船的 AI 船员、使用已打包 CC0 GLB 骨骼动画的海盗船员、惯性限制的敌船与真实炮弹发射事件、房主广播伤害/弹药/船员状态等功能。保留 V42 的所有游戏源文件、游戏资源及原版启动器。

**不是 V43 最终全部完工**。项目可通过本地源码测试和 HTTP 启动检查，但当前运行环境不能进入可操作的 WebGPU 实机进行驾驶、人物碰撞、设备可见性、动画姿态、帧率、多台 Windows 的实际检查。绝不可把逻辑测试当成实机 3A 验收。

## 4. Windows 优先验收步骤

1. 解压整个 ZIP，不能只复制单个 `src` 目录。运行 `START_STORMWAKE_V43.cmd`，在 Chrome/Edge 打开 `http://127.0.0.1:5173/?stormwake=1`。检查 Console（F12）没有错误。
2. 不接任务也应能登船；到绞盘 E 起锚，帆索 E 收/放帆，舵轮 A/D 转向与 W/S 调速，能离港并回港。
3. 站在甲板中央后部舱口 E，下舱。转头观察舱壁与船壳；用 E 爬回。快速转向/波浪运动时镜头不能穿甲板；甲板上的人员与货物不能漂离船体。
4. 到左/右舷炮位 E，左键射击、R 装弹。确认炮 HUD 显示装填倒计时，不能连续无限射击。观察击中敌船和敌弹打向本船的轨迹及破口位置。
5. 被炮击后进入舱底，用 `6` 木板靠近可见的破口长按左键 2.2 秒；破口封堵后流水停止，原积水不能自动消失。用 `2` 水桶舀水，再回甲板靠船舷泼水。
6. 在船体受到损伤后，观察第三名船员是否**先从材料处取板，走到舱口下舱，再走到受损位置修补**。F12 看是否有骨骼角色资源加载失败的日志。
7. 两个浏览器客户端进入同一 LAN 房间，一人掌舵、一人操帆/开炮；检查弹药、AI 船员位置、破口是否一致。断线重连持箱等仍属于待补完场景。
