# Tidewater STORMWAKE V36：严格验收与尚存质量问题

## 本轮改动是否真实落地

代码、GLB 和测试用例全部实际包含在此工程。未使用假链接、运行时占位材质或把原本的假动物修改名称来充当真实蒙皮模型。保留 V35 完整基础，不改海战、任务、船只或存档协议。

- `public/models/land/crab.glb`：项目自主制作的 34 根骨骼、11,060 三角面森林蟹。甲壳、腿、螯、眼、甲壳斑纹、齿突独立 6 套材质，6 段关键帧动作（Idle / Walk / Run / Attack / HitReact / Death）。Python 3 可用 `tools/build_land_crab_v36.py` 重建。
- `public/models/characters/joe.glb` / `marta.glb`：保留原 Microsoft Rocketbox 网格、贴图、骨骼、七段动作，在骨骼上增加七种由本项目编写的步行、奔跑、轻重击、闪避、受击、死亡动画。不是另购真人动作捕捉，也不声称是动作捕捉动画。
- `public/models/land/resident_{scout,watchman,courier,apprentice}.glb`：在 Quaternius 原骨骼上增加 Talk 手势，而不是只让弹窗出现文字。
- `public/models/land/boar.glb`：修复原 idle 时长只有 0.0417 秒（几乎静态）的问题；补上更长的待机、快速步态、受击和死亡片段。
- `src/engine/render/Skinning.js`：修复自研 WebGPU 材质组装时忽略 glTF `baseColorFactor` 的问题，保留螃蟹外壳、爪、眼等的 PBR 基本颜色。
- `LandRigRuntime.js`：所有人物职位都有严格校验过的本地资源表，13 个共享 GLB 的文件解析复用、同源纹理加载去重；每个场景实例使用独立骨骼矩阵及动画状态。
- `LandAdventure.js` / `LandCombatTiming.js`：挥击具有蓄力、扫掠有效窗口、收招，目标每击最多受到一次伤害；阻止穿过实体墙面和柱子的近战命中。第一人称刀光与检测使用相同攻击进度（尚非真实逐三角刀刃接触）。

## 仍未达到“完美/3A”的具体原因

1. **人物差异化不足。** 20 个村民有不同位置、名字、行程与对话；但其中 16 人共用 Joe/Marta 的两套外观和动画。独立职业服装、面部表情、唇形、手指动画尚未制作。新的身体动画为手工生成的标准循环，不是专业动作捕捉。
2. **森林蟹属于原创低多边形风格。** 已真正建模、制作骨架并有动作，离线几何可见 `docs/V36_crab_mesh_review.png`，但还缺高精雕刻/PBR 法线贴图、精细关节姿态、完整运动学 IK、足底落点自适应。
3. **攻击接触只是优化过的近似几何判定。** 使用扫掠前向胶囊、攻击阶段和实体遮挡；并非用真实武器蒙皮顶点与受击网格做连续碰撞。敌人攻击也尚未获得逐关节命中帧标记。
4. **没有高保真实体浏览器测试。** 需实际运行 Chrome/Edge WebGPU，观察尺寸、朝向、光照、贴图、LOD、遮挡、动画过渡、帧时间和长时间运行的资源泄漏；没有通过前不能标记为完成。
5. **许可与发布。** Quaternius、Rocketbox 的许可和署名记录继续留存；原创螃蟹遵循工程 MIT。对其余旧版 V25 海怪等使用的 CC-BY 来源，公开分发时应继续保留原署名文件。

## 如何本地验收

Windows 从完整工程目录运行 `python start_v36.py`（首次需要 Node.js 22、npm 安装依赖及 WebGPU 浏览器）；图形窗口手动走查三人称主角攻击、森林蟹 6 动作、野猪奔跑、20 村民对话、墙后无法受刀伤、上下灯塔，以及潜艇和海怪系统。自动测试：`npm run test:v36`。开发机可运行 `python tools/build_land_motion_v36.py` 或 `python tools/build_land_crab_v36.py` 复建关键帧和模型。所有操作均保持 Python 启动/脚本，不要求 `.sh`。

**结论：** 49 个 V35 角色/动作“缺项”在程序验收层面已补齐，但“真实 3A 画面达到完美”仍然没有通过必要的实体美术和性能审查。严格门禁脚本不会代表后者给出 PASS。
