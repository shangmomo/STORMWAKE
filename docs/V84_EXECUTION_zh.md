# V84 — 西侧晶岩湖厅与几何、侦察修复

## 本轮实现
- 新岩壳以同一网格渲染和碰撞，修正入口环面方向、两侧及尾端连接，增加真实几何细分与外壳起伏。旧矿井保留。
- 船长营地后方 (-549 的通道断面) 向西有连续扩宽湖厅，中心 (350,-551)，湖深约6米；岸边 (364,-549) 有调查路标，蓝色地面箭头和局部灯光引导。旧矿井水池仍存在；新湖与旧池共用裁切及水体判定，不是海洋水位。
- 单人自由视角 F 搜索镜头下方及周围8米的可站立干燥表面；检测碰撞、坡度、水位和到镜头的路径。失败不再强制返回旧位置，Shift+F 主动返回原角色。联机禁止传送。
- 原船长 GLB CPU 姿态采样正常；隔离旧版附加服饰以排除异常来源，保留原始骨骼模型。不宣称已确认 GPU 异常根因。
- 灰熊、狼、翼龙、魔鬼鱼、鹿、狐、野猪比例上调，部分移动和接触尺寸同步调整。保留原12米暴龙标定。

## 本地专项验证及局限
在本地原工程副本应用新地形参数、岩壳和独立侦察落地代码：25476三角面、38214条边均共享两面；化石谷道路1370个胶囊采样点无岩壳碰撞，湖厅岸路69个采样点通过，采样水域约308.75平方米、中心深约6米；侦察落地平地、水域、封闭障碍专项通过。仓库新增集成测试 npm run test:v84，尚未执行完整合并版本或真实 WebGPU 渲染测试。本版不是完整地下世界终版，湖厅尚无专属大型Boss、真实流体或完整生态。
