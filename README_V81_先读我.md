# STORMWAKE V81：机械升降与局部生态

完整解压，运行 `00_START_V81.cmd`（Windows）；其他系统可运行 `python3 start_v81.py`。沿用现有 Python 启动器及支持 WebGPU 的浏览器。不要覆盖旧存档备份，不需要合并旧版文件。历史资源和启动器仍保留。

- 沉岩洞采掘站：抵达矿样台调查后，沿采掘前厅寻找升降平台、呼叫开关和备用楼梯。单机 E 交互呼叫或操作平台，待门完全打开再进入/离开；多人暂时仅允许走备用楼梯。上层调查为新增一次性80金币任务，沿用奖励补发。
- 魔鲸号：原隔舱门交互不变；服务器直接裁决门状态。被夹区域有人时不允许关闭。舱内移动使用扫掠碰撞，远端船员使用既有骨骼角色资源（未完成 GPU 动画验收）。
- 捕捞：同一48米网格内鱼竿、拖网、蟹笼消耗共同鱼群预算，24份上限，每30秒有效游玩恢复1份，满舱自动放生不消耗。仅本地存档，非多人共享。
- 独立水体：采掘站水池及潜艇分舱积水不再以外海海平面判断摄像机介质。渲染须在真实 GPU 上进一步验收。

`npm run test:v81` 执行核心回归及两个四客户端协议用例。详见 `docs/V81_EXECUTION_zh.md` 和 `docs/V81_ACCEPTANCE_MATRIX.csv`。本版仍为开发版本，不是已签署最终发布验收的成品。
