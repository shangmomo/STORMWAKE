STORMWAKE V57 / 多人真正同步版

1. 解压整个 ZIP 到硬盘（不要在压缩包里直接运行）。
2. 双击 00_START_V57.cmd，选择单人 / 多人创建房间 / 多人加入房间。
3. 创建房间的电脑需安装 Node.js 22+，并在防火墙放行 TCP 5174。
4. 加入房间的电脑输入房主的局域网 IPv4 地址:5174；不能填自己的 127.0.0.1。
5. 游戏在每台电脑上使用 http://127.0.0.1:5173 本地 WebGPU 页面。
6. 看 README_STORMWAKE_V57_真实联机系统与验收.md 的 7 步双机验收。

V57 源码和本地服务逻辑已经测试；浏览器画面与跨机联机效果需在真实双机上确认。
